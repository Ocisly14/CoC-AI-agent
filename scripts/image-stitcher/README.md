# 街景拼接工作台

独立的本地图片与文字拼接编辑器，入口为 `preview.html`。运行时不需要第三方 JavaScript 依赖。

首次打开显示 2688 × 1536 空白画布，可自行导入图片；同一浏览器与本机地址下会恢复已保存草稿。操作台不依赖蓝鸟场景、粗模或任何预置图片。

## 操作

- 在画布或左侧图层列表选择图片，拖动移动；右下角手柄等比缩放。右侧可精确输入 X、Y、缩放和旋转。
- 曝光、亮度、对比度、饱和度、色温、色调及透明度分别作用于选中图层；四个边缘可独立羽化。
- 先用“差值”混合模式或降低透明度检查重复建筑，再调整位置与缩放；完成后回到“正常”，用羽化柔化接缝。
- 添加 PNG/JPEG/WebP，或拖入画布。添加文字后可调整内容、字体、字号和颜色。图层支持排序、隐藏、锁定位置、复制和删除。
- 空格拖动平移视图；滚轮缩放；方向键移动 1 像素，Shift+方向键移动 10 像素；Cmd/Ctrl+Z 撤销，Cmd/Ctrl+Shift+Z 重做，Cmd/Ctrl+S 保存工程。
- 保存工程生成内嵌所有图片的 JSON；打开工程恢复可编辑状态。工程覆盖、新建空白工程均可撤销，保留最近 40 步。
- 自动保存使用本浏览器、本机的 IndexedDB；更换浏览器、端口或清除网站数据后不保证保留，请用工程文件备份。
- 导出 PNG 包含全部可见图层、调色、混合和透明度；选框和棋盘格不进入导出。画布外内容会裁切。

## 边界

这是整体位置、等比缩放、旋转、调色与边缘羽化工具；没有局部透视变形、网格变形、画笔蒙版或自动几何配准。两张生成图中的建筑漂移可能需要进一步局部修绘，单靠羽化无法消除双影。

调色在浏览器解码的 RGB 通道上执行艺术化调整，不是 ICC 管理或物理重打光工具。原始图片不会被改写。无需账号，不上传用户导入的图片。

最多 40 层；单图最多 2400 万像素、最长边 16384、文件 40 MB；画布边长 64–8192、总像素最多 2400 万。大工程的实际可用规模取决于设备内存。

## 运行与验证

从仓库根目录运行：

```sh
python3 scripts/image-stitcher/serve.py
```

打开 `http://127.0.0.1:8846/preview.html`。使用 `--port 8847` 可更换端口。服务器只监听本机回环地址；启动目录与当前工作目录无关。迁移自旧操作台时保持原端口 8846，可继续读取原有本机草稿。

运行时无第三方依赖。`editor-core.mjs` 保存调色、坐标转换和工程验证；`editor-renderer.mjs` 是预览与导出共用的 Canvas 渲染器。测试依赖 `canvas`，精确版本在本目录 `package.json` 中声明。可先运行 `pnpm --dir scripts/image-stitcher install`，然后：

```sh
node --test scripts/image-stitcher/editor.test.mjs
```

8 项测试通过：默认色彩与 alpha、曝光/去饱和、旋转坐标逆变换、叠层/透明度/移动、羽化、调色缓存刷新与 PNG 编码、差值/文字、工程往返及非法数据。JavaScript 语法检查通过。当前未进行浏览器交互与跨浏览器视觉验收。
