# Grayhaven 大场景原型

启动：在仓库根目录运行 `pnpm --dir client dev`，打开 `/sandbox/grayhaven`（默认端口 5173）。这是独立的静态预览入口，无需后端、登录或模拟会话。

场景使用 Three.js，表现灰港镇的海岸、灯塔、码头、主街、汽车旅馆、红杉林、旧锯木厂和雷德利站建筑体块。已按艺术指导接入静态绘画素材：粉质木板与屋顶、不规则红杉贴片、分层岩岸、草地与干土笔触，以及暖光和冷色环境补光。保持简化的大场景尺度，没有使用游戏原作资产。

地貌参考 Half Moon Bay 的弧形海岸、宽沙滩与沙丘组合（[California State Parks](https://www.parks.ca.gov/?page_id=531)）。Grayhaven 小镇位于湾底低地，北、东、南三侧设置连续山坡和山脊；湾内为宽沙滩与湿沙带，两侧岬角保留岩岸。所有高度与坐标仍为叙事沙盘的示意尺度。

后续美术制作遵循 [Grayhaven 艺术风格指导](../../../../docs/superpowers/specs/2026-09-06-grayhaven-art-direction.md)：带粉蜡笔触感的手绘写实，包含研究依据、色板、材质与光照规则，以及原型改进顺序。

- 拖动平移、滚轮或双指缩放；`+` / `-` 缩放，`0` 回全景，`Esc` 关闭地点说明。
- 点击地图地点或目录条目，镜头定位并展开模组原文；相邻地点显示模组的实际步行时间。
- 远景仅显示主要标注，放大后增加户外地点标注。当前没有局部场景切换和室内空间。
- 午后、落日、蓝调与海雾滑块仅修改画面；没有驱动模拟时间、天气或角色状态，也没有调用模型。
- 建筑、树木、地形在进入页面时一次性构建，树木使用实例化绘制；每帧仅更新镜头、海面和标注。关闭页面时释放 GPU 资源。
- 红杉通过四种透明贴片形成疏密群落，避让道路、城镇和地标。相机保持固定朝向，贴片面向该方向；没有新增绕视操作。
- 绘画素材在开发时生成并随项目发布，来源、原始提示词和纹理预算见 [素材说明](./assets/README.md)。页面只加载两张图集；8 张分区 GPU 纹理约 10.67 MiB（不含阴影、帧缓冲等）。
- 建筑增加斜屋顶、山墙和随地势接地的基座；蓝调时只亮起少量暖色窗户。海岸采用有宽度变化的坡面、局部沙滩与成组礁石，海面保留低对比的缓慢笔触；独立的沿岸浪带表现分层推进、破碎泡沫与退浪湿润感。
- 午后采用更强的侧向太阳与冷色天空补光，普通材质不再自发光；树冠使用弯曲法线，让手绘贴片也有受光层次。这里的环境补光是艺术化的间接照明近似，不是实时多次反弹 GI。
- 林下斑驳光由实际树位生成世界坐标遮罩，仅调制太阳直射，不影响天空补光或灯具。遮罩随太阳方向重绘，光斑随场景固定，不叠加全屏动画噪点。
- 灯塔、守塔小屋和码头各有一个真实点光源，采用平方反比衰减；灯塔和小屋灯投射局部阴影。午后关闭小屋和码头灯，夕照与蓝调逐步增强暖光。
- 太阳阴影在桌面使用 3072 分辨率、窄屏使用 2048；两个局部阴影分别为 512 和 256。只在切换光照预设时更新，平移、缩放和调雾不重绘阴影。
- WebGL 不可用时仍可从目录阅读地点。支持减少动态效果偏好。

## 数据与布局

`grayhaven.generated.json` 由 `node scripts/export-grayhaven-sandbox.mjs` 从 `testmods/grayhaven` 导出。包含 16 个户外节点、19 条道路与 7 个沿路场所引用；沿路室内场所仅保留名称和 ID，不导出室内说明。模组修改后重新运行导出命令。

`layout.ts` 手工定义示意坐标和道路曲线控制点；地图不采用真实地理比例，视觉距离不代表步行时间。地形和额外建筑是氛围布景，并非新增可交互地点。道路连接和时间始终来自模组数据。

海湾版统一由 `shoreline`（植被后岸）、`coastWidth`、`waterline` 与 `coastalElevation` 描述岸带。地面与沙滩共享边界高度；山脊高于镇内低地约 100–200 个场景单位。山顶植被降低密度，建筑地标保留小块平整台地。码头与灯塔的示意位置随新岸线迁移，连接道路仍保留原有端点 ID、步行时间及沿路场所；码头长度、桩高、船位与港口灯也随岸线计算。默认镜头保留地形改造前的斜俯视方向、观察中心与缩放；回到全景及树木贴片朝向同步保持一致。

运行检查：`pnpm exec vitest run client/src/observer/grayhaven`；`pnpm --dir client exec tsc --noEmit`；`pnpm --dir client build`。

本地调试时可读取地图容器的 `data-load-ms`、`data-tree-count` 和 `data-render-stats`。后者约每 1.5 秒更新帧间隔中位数、P95、绘制调用和资源计数；帧间隔包含浏览器调度，不能当作 GPU 耗时或跨设备性能承诺。

## 本轮验证（2026-09-06）

- 模组边界与森林避让测试共 5 项通过；TypeScript 检查与 Vite 生产构建通过。构建仍提示大于 500 kB 的 JS 分块和 Browserslist 数据过期；Grayhaven 分块约 576 kB，gzip 161 kB，两张 PNG 共约 3.91 MB。
- 本机 Codex 浏览器 1280 × 720 检查了午后全景、主街与灯塔 235% 放大、落日、蓝调和 100% 海雾；地点目录、文字阅读、道路指引、标注开关与回全景可用，未捕获浏览器警告或错误。
- 午后全景一次稳定窗口：帧间隔中位数 16.7 ms，P95 18.2 ms，839 次绘制，212,352 个三角形，3,743 棵树。缓存重载的素材加载及场景初始化记录为 159 ms；不代表首次网络加载。9 个 GPU 纹理计数包含阴影，艺术素材估算仍为 10.67 MiB。
- 尚未进行低端设备、跨浏览器与完整显存分析。固定相机方向是树木贴片成立的条件。

光照修订后，测试增至 8 项，类型检查和生产构建通过；浏览器检查了午后全景、林缘 235% 放大、灯塔暖光和三种光照预设，未捕获着色器错误。原有 8 张艺术纹理之外增加 1024 的光照遮罩和 64 的灯晕纹理，含 mip 链的纹理估算合计约 16.02 MiB。`data-render-stats` 另列阴影颜色与深度附件的容量估算，均不包含驱动开销；上面的 159 ms / 839 次绘制等数字属于光照修改前的记录。

海湾修订增加 4 项地形测试，覆盖两侧岬角、三面山脊、沙滩宽度、岸带接缝及海岸地标。原来的模组关系测试继续适用。

海滩修订：码头合并为一座直栈桥，增加末端平台、栏杆和木板接缝。干湿沙带加入不规则潮线、细砂纹与风纹；漂流木、碎石、海藻和上滩草簇使用四组实例化网格。动态浪带与海面共用时间及氛围参数，不增加纹理或逐帧重建几何；隐藏页面及减少动态效果时停止推进。主视角与模组关系保持不变。12 项既有测试与类型检查通过；本次未做浏览器视觉验证。

海浪动态修订：`waterDynamics.ts` 将海面与泡沫合并为单张岸线网格，四组涌浪驱动几何起伏，六个独立浪组呈现不同间隔、强度、破浪缺口与爬滩回退。水面法线参与太阳受光；沿岸网格近密远疏，不增加纹理。新增 3 项生命周期测试，连同既有测试共 15 项通过。研究来源、参数与性能边界见 [海浪动态研究](../../../../docs/superpowers/specs/2026-09-06-grayhaven-water-motion.md)。
