# 矩形排笔与压力笔刷

2026-09-08。按用户修订，撤回“缺口补满 + 顺序缓存画布”实现，恢复原压力路径；新增可切换的矩形排笔草稿；最新修订改回原压力笔刷并取消矩形裁切。原始压力路径保持默认；以下记录早期迭代，最新起笔与接地行为见 [根部修复](../SHADOW_ROOT_FIX.md)。

- 笔带长轴沿投影方向，宽度由原基础笔宽决定。相邻等宽矩形的中心步长为 `width * (1 - overlap)`；overlap 每对固定随机取 0.30–0.60。整体统一缩放以适配物体投影宽度，不改变重叠比例。
- 每个物体的笔带按根部相对物体中心的方位角排序。俯视世界 XZ 平面，从 +X 起向 +Z 为顺时针；可反转顺序。
- 每条笔带按铺色、衔接、接触、修边、干刷顺序，在组内选取原压力笔刷的 Aui 05／02／06 Grain 配方。沿用原压力曲线、压扁、含漆和程序圆角扁笔尖；此前 full-stroke PNG 方案已被这次用户修订替换。
- 矩形仅安排路径和基础宽度。完整压力笔尖可以越过矩形侧边和路径端点；没有 UV 0–1 裁切，也不把首尾盖印压短来塞进矩形。仅在笔尖最大支持区外做性能剔除。后层按 alpha-over 覆盖前层的积色和干刷信息；没有覆盖率补洞或目标多边形填满过程。厚度是积色／干刷通道的视觉近似，没有新增真实几何高度或刷毛模拟。
- 接触组仅作用于贴地物体，原接地保护继续生效。矩形布局与捕获的物体／光向快照一起更新，镜头不重新随机；🌟 重画改变绘画版本。
- 资源：`settings.gd` 的五组配置可编辑，两支候选及各自权重、落笔概率、覆盖、笔带内长度／宽度／起点、积色强度分别保存。默认候选来自原压力模式的三种可用 Grain 配方。
- 实验室右侧算法选择新增“矩形排笔：原压力笔刷”；下方可切换组、调整概率／覆盖／积色、反转顺序、显示矩形和重画。原压力控制仍属于原压力模式。

早期抽出共享压力积分函数时，原模式曾保留原边界处理。最新根部修复已经让两种模式统一保留完整椭圆笔尖，并取消独立满覆盖接地补色；不再沿用旧版“原压力截图完全一致”的结论。

## 贴图叠画层：50%–120%，每矩形至多一笔

在原压力轮廓内追加此前生成的油画 PNG，作为积色／干刷纹理。按组权重先选一种用途，再选一张 PNG；每个矩形只采样这一笔，不沿长度循环或平铺。

以当前笔宽 × 原图可见部分宽高比换算未经纵向形变的笔长。原图宽高比独立于运行时统一纹理数组的 1024×384 存储尺寸；叠画长度固定限制为该笔长的 0.5–1.2 倍。矩形再长仍只放一笔，余段保留原压力效果。贴图起点沿用所选组的落笔位置。

贴图只改变当前压力覆盖内的颜料／干刷表达，不增加或削减覆盖，不用 PNG 替换圆润轮廓。实验室增加叠画开关及强度；五组分别保存 PNG 候选、选择权重和组权重。默认强度 0.35 为首轮对照值，视觉调整先看图讨论。

验证：`--bluebird-overlay-qa`。`qa/texture-overlay/` 保存同镜头的开关对照、轮廓遮罩和报告。GPU 实测长宽响应覆盖 0.1、0.5、0.8、1.2、4.0 倍请求，结果分别为约 0.5、0.5、0.8、1.2、1.2；叠画开关前后压力遮罩逐像素一致。
