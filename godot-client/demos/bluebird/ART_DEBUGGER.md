# 光照与美术调试

运行 `Godot --path godot-client --scene res://demos/bluebird/street_corner.tscn -- --bluebird-art-debug`。
F3 显示或收起面板。此启动方式启用最新矩形压力阴影和油画叠画。读取参数由用户在文件窗口自行选择。

## 增色范围

在「增色范围」勾选「手选贴图色相」，选目标颜色（只取 HSV 色相），调整范围半宽与边缘过渡。
实际筛选使用 Oklab 色相最短角距，跨红色的 0°/360° 连续；半宽 180° 选择全部色相。
「查看增色选区」显示色相筛选乘材质色度置信度，不包含光照、重要度和遮挡。
「日照增色权重」才包含光强、表面朝向、重要度、响应强度与太阳遮挡。

跟随光色模式保留原始 15° 内充分匹配、65° 外不增色的默认行为，也保留光源色度置信度。
手选模式以目标色相替代光色色相，不再用光源色度置信度压低白色阳光下的增艳。
两种模式都保留材质色度置信度；灰白材质几乎没有可增加的色度。
选择不改贴图文件、不替换基础光照乘色、不影响提亮与低色度材质的原有轻微染色。

## 参数关系

| 参数 | 作用 |
| --- | --- |
| 日照增色响应 | 放大有效权重；范围未选中或无直射光时无效 |
| 日照饱和增益上限 | 限制色度倍率的额外增加；0.2 的理论上限为约 1.2 倍 |
| 日照提亮上限 | 受重要度、朝向、光强与原明度保护影响的提亮，不受色相选区控制 |
| 重要区域对比度 | 对重要区域围绕明度中点拉开亮暗，明度改变量有软限制 |
| 对比度明度中点 | 比它亮的部分提亮，比它暗的部分压暗 |
| 整体饱和度 | 合成照明后的色度倍率，包含阴影；1 中性，0 灰度 |
| 弱化低重要区域细节 | 提高后在低重要区域混入较粗贴图层级 |
| 重要度倍率 / 曲线 | 重映射原重要度数据；默认 1 / 1 不变 |

日照增色使用软上限，响应很大后继续提高会逐渐不明显。最终色域映射也会压缩越界的色度。
这些控件作用于 NPR 接收材质；玻璃等保留原生材质的表面不参与美术调色。

## 保存与对比

「当前设为 A」固定基准，「对比 A / 返回 B」在同镜头比较光照与美术参数。
「另存新参数」保存 B；查看 A 时保存仍保存保留的 B。
每次保存到 `user://bluebird-art-presets/art-日期_时间.json`，同秒重名自动增加编号，不覆盖旧文件。
「选择参数读取」打开 JSON 文件选择窗口，默认进入该参数目录，可选择任意历史版本。
旧文件 `current.json` 仍在同一目录内，可直接选取。保存版本为 3，包含时间模式、时刻和背景色。
旧版 v1 在内存中补入默认色相参数，v1/v2 使用手动光照模式；读取不会覆盖原文件。无效文件不会部分应用。
截图另存 PNG 和当时参数 JSON。镜头记录供参考，读取参数时不改变镜头或笔触布局。

## 昼夜时间条

「光照」页顶部新增 00:00–24:00 时间条、清晨/正午/日落/午夜按钮、播放/暂停。
拖动自动启用时间模拟；约 120 秒播放一天，跨午夜循环。保存与 A/B 包含时刻及时间模式，读取不自动播放。
太阳在 06:00–18:00 为主光源，其他时段为月亮；场景含独立的 Sun、Moon 方向光节点，任意时刻只启用一个。
两种光共用当前 NPR 增色和笔刷阴影管线，主光的方向与阴影捕获同步发布。

这是一套美术预览曲线，不计算纬度、季节、月相或真实天文位置。太阳最高 60°、月亮最高 45°；
接近地平线时强度渐归零，主光高度最低 5°以约束阴影长度。正午太阳强度 1.1，午夜月光 0.16。
太阳低空偏暖、高空较白；月光使用较弱的冷色，环境光与背景色随昼夜连续变化。
太阳和月亮不同时累加直射照明，晨昏的环境光负责交接过渡。

时间改变保持曝光、对比度、饱和度、重要度及增色参数。手动修改主光方向、颜色、强度或环境光会退出时间模式，
并保留当时的光照作为手动调整起点。截图、A/B、读取文件会暂停播放。

验证命令：`Godot --path godot-client --script res://demos/bluebird/tools/day_night_qa.gd -- --bluebird-art-debug`。
已验证四个时段实际渲染、单一光源激活、太阳/月光与阴影方向一致、午夜循环、曝光保持、A/B及v3存取、v2迁移。
结果 `/private/tmp/bluebird-art-debug-qa/day-night-validation.json` 为 `failures: []`。
