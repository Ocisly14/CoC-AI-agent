# 叙事性油画写实 · 美术手册

版本 1.1 · 2026-09-07 · 全项目规范 / Grayhaven 首个样板

**现实底色＋心理表现。让风景、房屋与使用过的器物成为叙事载体，让文字有安静、清楚的阅读空间。**

本文是当前美术方向的唯一入口，取代先前以《奇异人生》为主参考的粉质手绘方向。历史文档中的构造研究、世界数据约束和技术记录仍有效。本文规定目标，并不表示运行时已完成改造。

**建筑材质采用“写实油画底材＋独立表现性叠加”。** 底图按真实覆盖面积描绘木板、砖石、灰泥、屋面与金属，可以有克制的手绘笔触、色彩概括和油画质感；这些笔触服务于材料形态与质地。底图生成时就包含适量剥漆、露底、污渍与风化，去掉的是装饰性小笔刷色块，不能连同真实损伤一起清除。材料与日常磨损成立后，再像现有大色块一样添加可单独关闭的宽刷、擦色和破边。基础层可以有绘画语言，但不能把后续的大块表现性笔刷提前铺满底图，也不要求底图呈现照片或扫描质感。

## 1. 参考与取舍

巡回画派作为人物、生活、风景与自然光的研究来源，不将它简化为单一滤镜或统一笔刷。借鉴其对劳动、居住、材料和环境关系的认真观察；《极乐迪斯科》作为游戏绘画表达参考，重点研究可信建筑与材料如何支撑大色面、表现性笔触、局部完成度和视觉注意力。本项目将“巡回画派方向”转译为写实观察与克制绘画表达：底材本身可以画出来，整体光色、边缘取舍与后续局部叠加进一步组织画面；这不是对整个画派统一技法的定义。

参考入口：[特列季亚科夫画廊：巡回画派](https://museum.tretyakov.ru/publications/10-faktov-o-peredvizhnikakh/)、[Aleksander Rostov 作品集](https://www.artstation.com/rostovjanka)。这些入口用于研究，不将本文的 HEX、粗糙度或灯光参数归因于原作工程。

**所有参数是项目原创制作起点。** 图板为 AI 辅助概念设计，SVG 为可编辑界面设计；均不是游戏实机截图、测绘图、已交付 GLB 或已验证着色器。

Grayhaven 的 1985 年北加州、七月、衰退渔业与伐木业、葡裔社区来自 [模组设计](../../testmods/grayhaven/DESIGN.md)。保留当代北加州木构、红杉与海雾，不引入十九世纪俄国服装建筑，也不改变为秋天或永夜。

## 2. 四条总规则

1. **结构可信。** 门框承重、锅具厚度、台阶落地、地形接缝和日照方向在简化后仍成立。
2. **使用留下痕迹。** 把手抛光、杯口磕碰、墙脚受潮、迎海面盐蚀；尚在维护的物件保留干净部分。
3. **注意力决定细节。** 路口、门、可交互物件边缘清楚；林内、远景和非焦点区域允许融合。
4. **心理表现有边界。** 强烈偏色和边缘破裂只由明确叙事状态触发，不能增加事实、暗示秘密或篡改标注。

## 3. 色彩与明度

以下 HEX 为 sRGB 美术参考，进入材质后需正确转换色彩空间；灯光、曝光、雾和色调映射都会改变最终颜色。

| 名称 | HEX | 主要职责 |
|---|---|---|
| 骨白 | `#E7DDC8` | 阅读纸面、浅漆、柔亮部 |
| 炭墨 | `#24282B` | 文字、深底、局部深暗 |
| 暖灰褐 | `#8A7968` | 旧木与建筑中间色 |
| 黄赭 | `#B58A50` | 干草、旧漆、暖色面 |
| 铁锈红 | `#984F43` | 器物、工业遗存、危险语义 |
| 海雾灰 | `#A8B3AE` | 远景与空气透视 |
| 深海蓝绿 | `#496669` | 海面、环境冷色 |
| 苔橄榄 | `#666D50` | 林地与植被 |
| 阴影灰紫 | `#696373` | 背光面、冷暖交界 |
| 灯火琥珀 | `#D9AE70` | 灯具、窗光、强调 |

全景先分成亮、中、暗三组大关系。用约 70% 主调、25% 辅助色、5% 强调色练习色稿，不实施像素配额。低饱和仍保留海水蓝绿、木墙暖灰、阴影灰紫之间的差别。

白天允许亮部舒展；深暗集中在屋檐、接地与林隙。夜间保留入口和主要空间关系，使用真实灯光形成视觉岛。骨白不能直接成为墙面的自发光颜色。

## 4. 材料、笔触与边缘

材料纹理与绘画笔触分别控制尺度。板宽、砖块和木纹由真实材料尺寸决定；宽刷、擦色与破边由建筑上的构图位置和目标视距决定。不能为了让笔触更醒目而放大底图，使木板或砖石变成不合理的巨块。基础材质可以用写实油画的笔触概括木纹、旧漆与灰泥；笔触服从材料方向、真实尺度和形态，不预先铺满与材料无关的大色簇。

| 尺度 | 内容 | 制作与观察 |
|---|---|---|
| 大 | 林冠群、屋顶面、海陆关系 | 缩至 320 px 宽仍成立；先画后细化 |
| 中 | 独立叠加的宽刷、坡面擦色、冠层亮斑 | 默认观察距离可见，按局部构图安排 |
| 小 | 绘画层的干笔露底、少量颜料边缘细节 | 近景少量出现，远处经 mipmap 消失；材料描绘所需的克制小笔触可存在于底层 |

笔触跟随表面方向，使用局部 UV 或世界空间映射。转角不拉伸，镜头移动不游泳。改变笔触尺度、色面断续与边缘完成度，而不是覆盖全屏噪点。

真实木纹、细划痕和材料颗粒属于底材细节，不能仅因形状细碎就归为“小笔触”。近景读材料，默认视距读构件与色面，远景读体量和明暗。关闭绘画层后，建筑必须仍然成立。

清晰边缘用于门框、屋檐、物品轮廓与交互焦点；柔边用于同材质内部与非焦点；消失边缘用于雾中远树、暗部木墙与背景合并处。反对密集平均描线、整屏模糊、塑料高光、统一泛黄和均匀做旧。

## 5. UI：文学档案式

### 布局与字体

桌面世界占主要区域，右侧阅读栏承载地点、物品、事件。1440×900 使用 400 px 栏，1280×720 使用 360 px 栏；窄屏 390×844 使用底部阅读面板，折叠时 300 px 高，展开后可占可用高度 80%，正文内部滚动。顶部和操作区留安全间距，地图焦点在剩余可见区内构图。

标题字体栈：Noto Serif CJK SC、Source Han Serif SC、Songti SC、serif；正文：Noto Sans CJK SC、Source Han Sans SC、PingFang SC、sans-serif；拉丁标题与正文分别优先 Noto Serif、Noto Sans。SVG 保留文字，缺失指定字体时使用上述回退；不随本包分发字体。上线时需另行打包合法字体与 CJK 字形子集。

正文 16–18 px，行高 1.65；标题 24–36 px；辅助信息 13–14 px；功能文本不低于 14 px。中英文信息分别排版，数字启用等宽数字。不得把英文强制全大写和宽字距规则套到中文正文。

### 材质与组件

长文用骨白底、炭墨字；地图浮层用不透明炭墨底、骨白字。纸纹只允许出现在边缘和留白，不降低正文对比。分隔线、索引、页码和克制印刷标记构成秩序，不堆叠装饰画框。

图标用同一套 24 单位线刻 SVG，描边 1.5–2，默认放入至少 44×44 px 命中区。装饰图标不承担独立含义。既有肖像保持比例裁切与清楚姓名，可缺省为姓名首字容器，不新生成角色面孔。

| 状态 | 视觉表达 | 行为要求 |
|---|---|---|
| 默认 | 明确文本与细边界 | 不依赖纸纹识别按钮 |
| 悬停 | 轻微底色明度变化 | 不改变布局尺寸 |
| 选中 | 赭色侧线＋实心标记＋文字状态 | `aria-pressed` 或相应选中语义 |
| 键盘焦点 | 2 px 高对比外环＋2 px 间隔 | 不只用颜色变化 |
| 不可用 | 降低强调＋原因文字 | 不隐藏必要信息，不只降透明度 |
| 加载 | 稳定占位＋“正在读取” | 不伪造物品与事件内容 |
| 错误 | 铁锈色图标＋可读原因＋重试 | 保留当前可读信息 |
| 未知 | 统一“未获知”占位 | 不暴露原始名称、标签或秘密 |

正文对比目标 4.5:1，关键非文本控件目标 3:1。黄赭仅用于装饰或深底强调，不能直接作为骨白底小号正文。可读正文辅助色使用 token 中更深的派生色。

过渡 120–220 ms，位移最多 8 px。减少动态效果时取消装饰位移、漂浮与脉动，保留必要状态更新；关闭后静帧仍成立。

## 6. 场景与物品

详见 [制作规范](production.md)。建筑用屋顶形式、宽深比、门洞和附属体量区分；地形采用连续坡面，接缝、门槛与底座必须接地。优先完成现有建筑，不增加新地点。

蓝鸟样板必须同时表现临街两层主楼、较低单层后厨翼楼、堂座、后厨与楼上住处。堂座有临窗绿皮卡座、长柜台、红皮转凳；后厨有钢面工作台、灶具与汤锅；楼上用窗边摇椅、圆桌、五斗柜与铁床组织生活空间。平面和物品位置以模组及现有模型为准，概念板不得充当精确平面图。

物品分环境填充、可交互、叙事重点三级。轮廓、可见凹凸、孔洞、接触和遮挡由几何承担；细裂纹、浅划痕、补漆用贴图。六件样板全部映射到现有场景引用，钥匙是钥匙钉板的视觉组件，系缆桩是复数条目的实例。

## 8. 光照与空气

保留连续 24 小时变化，使用 [光照参数表](lighting.json) 的六个关键时刻校准。表中亮度是同一场景的归一化美术权重，不是勒克斯、太阳测量值或可直接赋给 Three.js 的 intensity。时间沿用现有太阳路径，不用概念图替换天文或天气逻辑。

一个明确主光塑造体积，天空光与地面反弹托住暗部。接触阴影稳，半影随距离变柔；午后温暖中性，夕照琥珀与灰紫分离，夜间冷灰承托真实暖灯。材质可分辨，黑铁不变白塑料，木头不自发光。

室内先有实际窗、门、灯位置，再调亮度；蓝鸟的乳白吊灯和二层台灯分别形成照明区域。剖视隐藏外观后，物理遮光仍由现有阴影壳/遮光策略保证。阅读焦点通过合理光源与有限反弹建立，不用无来源全室泛光。

近景保留材料，中景简化纹理，远景趋近雾色。沿用现有室内雾排除，不用全屏灰蒙版代替空间。浓雾可隐藏远地标，不能同时抹掉当前入口和物品。

水面保留宽阔断续反射带；玻璃表现少量简化大块反射；高光不均匀闪烁。材质粗糙度范围见 materials.json。

## 9. 天气与心理表现

| 效果 | 画面规则 | 状态与关闭规则 |
|---|---|---|
| 海雾 | 按深度和地形形成层次，近处入口清晰 | 从可见天气数据读取；预览可独立调节 |
| 雨 | 稀疏方向线、湿面大块反射，降低细闪 | 不凭视觉改通行状态；减少动态时停雨线 |
| 烟 | 少量柔边色团，上升节奏缓慢 | 必须有明确来源，减少动态时静态弱化 |
| 火 | 小面积暖光、克制飞星与影子变化 | 来自已有有效火源；样板测试不代表发生火灾 |
| 心理偏移 | 周边局部灰紫/锈红分离、边缘断裂 | 默认关闭；明确事件才触发，建议 0.6–1.2 秒，总量可归零 |

心理强度定义为 0 正常、0.35 轻、0.7 强，均为制作参考。中心交互区与 UI 不扭曲；不新增人影、眼睛、光点、密码或可被误读为事实的物件。静态主观样板是效果研究，不证明模组内发生此事件。

## 10. 工程衔接与跨模组

UI tokens、材质表、灯光表和资产清单属于版本化的设计输入，字段职责和单位在各文件内自述。当前不接入客户端、不替换材质、不更改后端 API 或世界状态 schema。

后续 Three.js 实现继续使用现有材质补丁组合、天空/反弹近似、软阴影、雾和按需加载。不得直接覆盖其他补丁的 `onBeforeCompile`。材质资源需显式释放，切层与退出恢复原状态。Godot 后续映射同一语义表，具体 shader 与材质资源单独适配。

剖视的美术契约仅规定“遮挡让位、室内内容与接触成立、建筑遮光保留”。当前仓库另有物体级剖切设计，本文不锁死椭圆、抖动或某种隐藏算法，不改写那份设计。

其他模组可以替换地域材料、时代器物、局部色板、雾色和灯具；保持语义颜色职责、排版、笔触三级、LOD 目标与信息可见性规则。具体年代事实由对应模组重新查证。

## 11. 交接门槛

按灰度构图 → 色稿 → 场景/物品 → UI → 光照/天气 → 一致性复核的顺序阅读本包。每张板在 boards.md 标明几何、贴图、光照、UI 的职责和概念偏差边界。

概念审查：320 px 灰度仍可读主要地形；六件物品的剪影与材料明确；七张板并排属于同一画风；夜间与雾天焦点可辨。UI 审查：三个目标尺寸、中文/英文、正文对比、44 px 控件、长文滚动与状态表达。

工程阶段另验：真实模型/材质、加载失败与快速切层、拾取与可见性一致、相机变化不游泳、昼夜无跳色、剖视遮光、DPR 与 mipmap、减少动态、浏览器截图与设备性能。本轮只验设计与静态样板，不以概念图声称运行时完成。
