# 场景与物品制作规范

版本 1.0 · 配套 [美术手册](README.md)。此文件为制作交接标准，本轮交付视觉板和设计数据，不包含生产模型。

## 1. 坐标、尺寸与交接

离线作者资产采用米、Y 向上、物品正面朝 +Z、右侧 +X，静态物品 pivot 放接触底面中心；悬挂物放悬挂点，门的子节点 pivot 放铰链。导出 glTF 2.0/GLB 时烘焙非均匀缩放、核对法线，保留合理命名与材质分组。

现有沙盘使用示意单位，不能把 1 米默认为 1 场景单位。导入器必须依据宿主模型标定 `authorMetersToSceneUnits`，存于作者清单；本轮不为全镇指定虚假的统一比例。已建建筑尺寸沿用当前代码，不用本规范的物品米制建议反向缩放整个城镇。

每个资产交接：作者源文件、GLB、贴图源文件、导出贴图、预览图、清单。清单标明语义 ID、组件关系、作者尺寸、pivot、正面、LOD、材质槽、阴影/剖视职责、贴图空间与来源。源文件按颜色底层、笔触、磨损、文字/标记分层；AI 概念 PNG 本身是扁平参考，不宣称为分层纹理源文件。

命名格式：`gh_<place>_<object>_<variant>_lod<N>`；材质 `mat_<family>_<finish>`；贴图 `<asset>_basecolor|normal|roughness|metallic|ao`。示例 `gh_lighthouse_enamel_mug_a_lod0`。LOD0 为近景、LOD1 街区、LOD2 总览，与 UI 层级名称明确对应。

## 2. 几何预算与 LOD

以下为第一轮作者预算上限，不是已测性能承诺。可见像素收益优先，实际场景仍按设备测量调整。

| 类别 | LOD0 三角形目标 | LOD1 | LOD2 | 要保留的内容 |
|---|---:|---:|---:|---|
| 小物品 | 500–2,000 | 100–500 | 0–80 | 主轮廓、重要孔洞、接触面 |
| 重点小物品 | 1,000–4,000 | 250–1,000 | 0–100 | 功能结构、识别细节 |
| 柜体 / 桩等中物品 | 500–3,000 | 150–700 | 50–150 | 门片/桩头、比例、支撑 |
| 建筑外壳 | 8,000–25,000 | 2,000–8,000 | 500–2,000 | 屋顶、入口、附属翼楼 |
| 单层室内 | 15,000–50,000（含结构，不含独立道具） | 按需隐藏小件 | 不加载 | 地板、墙体、楼梯、主要家具 |

以物品投影包围框最长边为参考：小于 8 px 不显示细小独立物件但保留宿主身份；8–32 px 读剪影；32–96 px 读结构；大于 96 px 展示近景细节。转换有 15% 迟滞。受控重要物件可保留图标/标签，但不能为了可见性把模型夸大成巨物。

六件样板的三级视觉示例见 [物品板](boards/04-objects.png)：近景主图、结构缩略、剪影缩略。小钥匙的总览示例在钉板内合并，而非单独悬浮显示。

森林沿用实例化和现有固定向贴片；近景主干用真实几何与分组树冠。海面使用连续网格和宽阔色带。灯具数量、纹理数和阴影缓存预算以后续实测为准，不以堆灯补足绘画明暗。

## 4. 蓝鸟与剖视

外壳：临街两层主楼、较低单层后厨翼楼、阶梯假立面、蓝招牌、橱窗与角板。地板不能与外壳封盖共面；后厨无新增后门。堂座到后厨用弹簧门，楼梯从后厨通往楼上。

楼上：客厅和卧室、面街窗、摇椅、圆桌、五斗柜、铁床和床头灯。概念板中的家具方位只为构图示意，不覆盖已有房间连接、楼梯端点和物件锚点。

作者分组：`shell`、`roof`、`wall_upper`、`wall_low`、`floor`、`stairs`、`contents`、`fixtures`、`shadow_proxy`。组名是离线交接语义，导入器映射到实际工程的剖视机制，不能直接假设现有 runtime 识别这些名字。

上墙/屋顶可让位，地板、低墙、家具、灯具和当前楼梯保持完整。隐藏视觉外壳不能删除建筑物理遮光；阴影壳闭合并保留真实门窗开口。室外近景树干、树冠、根撑分离，保留林下物品。

## 5. 材质与贴图

八类基础见 [materials.json](materials.json)。粗糙度为 0–1 的作者建议，法线强度为相对单位。金属度按真实材质使用：裸金属 1，漆/锈/搪瓷 0，通过遮罩区分，不用整物件中间值混成塑料。

基色与可见发光贴图使用 sRGB；normal/roughness/metallic/AO 为线性数据。法线使用 glTF / OpenGL +Y 约定。AO 只保留克制的局部接触与缝隙，不固化大面积方向阴影。基础色不画入夕阳高光、窗光或长投影。

2K 图集用于共享材料，1K 独立纹理用于重点物件；非重点可降至 512。UV 以实际作者单位标定，木板在相邻楼层对齐。图集单元留至少 16 px 扩边（以 2K 源尺寸计）；独立重复材质使用无缝图，低 mip 层仍需检查串色，必要时分离贴图。

纹理源文件保留色面、方向笔触、磨损、文字四类层；输出 PNG 为交换格式，后续 Web 发布可以评估 KTX2。一个 2048² RGBA8 完整 mip 链约 21.33 MiB，一个 1024² 约 5.33 MiB，压缩文件大小不代表显存；避免无目的堆叠独立 2K 图。

## 6. 生产顺序与质量门

1. 从现有模块、布局和模型确认结构，记录事实/美术建议。
2. 灰盒验证比例、落地、轮廓、通道、剖视与拾取代理。
3. 绘制同一构图的灰度与色稿，按视觉板调整大关系。
4. 添加方向性油画色面，区分八类材质；最后才加细小磨损。
5. 制作 LOD 和材质共享，核查远景闪烁与贴图尺度。
6. 六时刻、室内日夜、海雾和近景检查；核查说明文字与图像不泄漏模组事实。
7. 工程集成后在真实设备检查资源释放、帧时、首次加载与快速切层。

只对机器可验证项做自动检查：引用 ID、尺寸字段、色彩空间、token 对比度、SVG 几何和文件完整性。艺术一致性、灰度层次与可读性必须看图，不能靠测试数量宣称通过。
