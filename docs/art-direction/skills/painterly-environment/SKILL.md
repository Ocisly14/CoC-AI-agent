# 油画场景制作

把参考图的构图、材料、色彩和笔触转译成可编辑的三维场景。优先实现用户选定的美术语言，不为了通用材质库、无缝平铺或自动化方便牺牲风格。

## 开始与续作

- 先查看用户参考图、当前有效美术指导、结构图和已有模型。检查旧指导是否已被新版本替代；用户本轮明确修正优先于历史设计。
- 确定建筑体量、年代地域、街道关系、目标镜头、可见距离和本轮范围。沿用已确定的尺寸、出入口及场景身份，不凭概念图重写地图或剧情事实。
- 默认关注建筑与场景。内部结构图不意味着授权制作家具、器物或人物；未包含在任务中的独立物品仅可用标注或占位体表达布局。
- 完整制作按下面七阶段推进；续作从最早尚未成立的阶段开始，复用已完成成果。用户只要求某一阶段时，在该范围内交付。
- 阶段检查由代理先完成，保存可审阅结果后继续已授权工作，不把每一步变成强制确认。只有影响结构且无法从上下文解决的矛盾才向用户澄清。
- 图像生成与编辑使用当前可用的图像生成工具；使用时遵守其技能和工具要求。建模可用 Blender 的 Python 接口或已有集成，不预设必须安装 MCP。工具缺失时明确缺口，不用占位图冒充完成资产。

## 1. 制作视觉参考图

先建立亮、中、暗的大关系，再确定色稿、笔触尺度和边缘分工。若用户提供概念图，保留其关键设计并衍生场景专用参考；已有明确通过的参考无需重复生成。

从画面中提取：主次体量、屋顶与立面形式、入口焦点、主辅色、材料方向、硬边与消失边、光向和使用痕迹。将“油画感”落实为可描述的表面和色块，不能只写风格名称。

**交付：** 主参考图、必要的材料／笔触局部参考、简短设计约束及来源记录。区分概念表现、已知构造和待推定内容。

**检查：** 缩小后仍能读出主体轮廓、入口焦点与主要色块；不靠密集颗粒、全局描边或滤镜制造风格。

## 2. 制作外部三视图

默认制作正立面、侧立面、俯视图；这是用于建模的正交投影，不是三个透视美图。街角建筑明确哪侧为正面，背面或另一侧存在独立结构时补图。

各图使用同一比例、楼层基准与部件编号，统一建筑宽深高、退台、屋顶轮廓、门窗定位和地面标高。尺寸依据区分为已知数据与设计推定；生成图中的尺寸文字需校订。

**交付：** 带清楚标签的三视图、尺寸表，以及需要补充的立面。

**检查：** 在视图之间核对开窗、转角、檐口、屋顶和楼层。图像生成容易产生视图矛盾，先纠正再建模，不能把错误直接交给几何承担。

## 3. 制作内部结构图

逐层绘制平面，标清墙厚、门洞、楼梯、楼板、净高和功能区；补一张能说明楼层关系的剖面或剖轴测图。检查内外门窗对应、楼梯落点和通行空间。

**交付：** 各层结构平面、关键剖面、可拆分屋顶／外墙／楼板的分组说明。范围之外的家具只做功能占位。

**检查：** 内部空间能装进外部体量，楼梯不撞楼板、门洞不被结构堵塞，剖视分组能展示需要查看的空间。

## 4. 建立场景白模

依照校准后的结构图，用统一单位建立地基、主体、楼板、屋顶、内墙、门窗洞和必要台阶。采用中性材质，不提前用复杂纹理掩盖体量问题。

分离需要剖视的屋顶、墙体和楼板，设置可理解的名称、原点和层级。优先解决轮廓、厚度、凹进、接地和遮挡。

**交付：** 可编辑白模及与结构图对应的正交渲染、街角视图、室内剖视。

**检查：** 实际渲染与参考逐项比较比例、退台、入口和空间关系。白模不成立时回到结构阶段修正。

## 5. 添加建筑构造细节

先补影响轮廓、投影和接触的结构，再补近景细节：门头、招牌框架与支撑、窗套与窗台、檐口、雨棚、排水沟、水管及固定件、屋顶通风口、泛水、门槛和建筑固定灯具。按具体参考取舍，避免把清单机械套给每栋房屋。

几何负责明显凹凸、孔洞、厚度和轮廓；浅划痕、漆色修补、细裂纹留给贴图。构件有真实连接与排水方向。可读招牌文字单独排版，校对后应用，不依赖生成图中的文字。

**交付：** 细化模型、关键节点近景、构件列表；保留白模版本。

**检查：** 构件不悬浮、不无故穿插，目标视距下有收益；不增加未授权的独立物品或剧情线索。

## 6. 制作底层基础贴图

按建筑实际材质分区制作专用贴图。基础层本身应有参考图的绘画语言，同时保存材料辨识所需的小细节：木板方向和接缝、旧漆露底、屋面搭接、金属锈蚀与局部修补。

先在代表性墙面试贴、实际渲染，再推广。UV 以物理尺度校准，避免楼层间板宽突变和大墙拉伸。源图分辨率按实际观察需求选择，不把某个固定尺寸视为质量保证。

基色不烘入方向性灯光、强高光或长投影；粗糙度等数据图与颜色图分别处理。木漆、裸木、金属、玻璃各有表面响应，不能全部变成塑料或同一种哑光。

**交付：** 基础贴图、UV／材质分区、已贴图模型及固定光照下的渲染，保留独立基础版本。

**检查：** 近景能读材料与使用痕迹，远景细节自然合并；切换光向仍可信。

## 7. 选择性叠加大色块油画贴图

先阅读 [局部绘画与材质交付](references/paint-layering.md)。这一步在完整基础层上补充画面组织，不能把原有小细节整体替换掉。

按照墙面的空白区域、构造转折和主次关系安排少量宽大的色块簇。笔触以世界尺寸和目标画面占比控制，正常视距下可见；不要把许多细碎划痕误当成大笔触。

先准备与参考相符的不规则形状库，再在模型上选取和安排：除宽刷外，包含偏心爆裂、断续放射、撕裂刮擦及骨白破边。用偏心、缺口、不等长分支和倾斜方向打破机械感；突兀的大横条应回到独立基础层重做，不能继续用更多贴图遮盖。角度与数量服从具体构图，不固定套用案例数值。

同色系通过明度、冷暖和少量色相变化产生突出感。允许色块中心局部实盖，边缘断续露底，色块之间继续呈现原始材料。复用已合适的旧笔刷；骨白／浅漆可选择性用于转角、墙边和墙脚，不能形成整栋统一白描边。

先为每个主要材料面确定一个主色基底，再在相近色范围内组织涂块；主色应在整体观察中持续可读，不把同一表面拼成彼此无关的彩色块。素材库按色系扩充，而非给所有形状随机换色。

屋顶也是主要绘画面，不能仅完成外墙就默认整栋风格成立。根据屋面材料保留基底、搭接和细节，用相近色的宽大、不规则涂块补充层次。平屋面按XY与高度／朝向限制投射，坡屋面按自身切线基准处理；笔触经过低矮泛水件时连续覆盖，避免贯穿到烟囱竖面或下方室内。最终分别检查屋顶整体与近景。

连续的绘画笔触经过窗框、窗台、转角板或相交外露管道时，应共享立面投射并覆盖对应构件，不能因为材质槽不同而在墙边截断。保留构件的原有结构与表面响应；用投射深度和目标区域限制覆盖范围，玻璃、内墙及招牌文字按设计范围单独处理。

**交付：** 独立笔刷源图与遮罩、可编辑放置参数、基础与油画层分开的 Blender 文件、按目标渲染链路烘焙的交付模型及同机位前后对照。

**检查：** 基础层切换后完整保留；大笔触的尺度、角度、缺口匹配参考；同一笔触跨墙面与构件连续，且不污染无关表面；门窗、招牌和入口清楚；不是全覆盖污渍层或屏幕滤镜。提供跨窗框／窗台的实际模型近景验证。

## 交接

保存七阶段中本轮实际完成的成果，区分概念图、实际模型渲染和运行时截图。渲染比较固定镜头、光照、曝光与色彩管理，避免靠更换灯光掩饰材质差异。

提供可编辑源文件、必要贴图、适用的 GLB 及近／中／远景预览；有内部范围时提供剖视。记录单位、贴图用途、色彩空间、层级和重建入口。验证导出贴图依赖完整、材质外观与源文件一致；未测试的运行效果或性能要如实说明。

本 skill 不自动包含托管或部署。用户未要求托管时交付本地文件；复用旧项目的发布配置不构成发布授权。

如在 Grayhaven / Bluebird 项目续作，另读 [Bluebird 案例定位](references/bluebird-case.md)，将其中数值作为案例而非通用约束。
