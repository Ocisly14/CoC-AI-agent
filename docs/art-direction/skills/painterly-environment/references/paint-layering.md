# 局部绘画与材质交付

在第七阶段，或用户要求“保留底纹，加大块油画笔触／白色墙边”时读取。

此处“底纹”指按真实覆盖面积校准的写实绘画材料，包含合理接缝、表面细节与使用痕迹，可以有描绘这些材料的克制油画笔触。底材与表现性叠加层分别控制映射和尺寸；关闭叠加层须恢复完整写实油画底材。历史基色中失真尺度或抢夺材料识别的大笔刷需先修正，不能误当成合格底材继续叠加。

## 先判断画面需要什么

把表面区分为三种区域：保留原材质的安静区、集中绘画的重点区、让两者衔接的破碎边缘。由参考图和建筑构图确定位置，不用均匀随机撒点或覆盖百分比代替美术判断。

大色块的职责是让一面墙在远处形成几片有关系的颜色。它可以有局部厚实中心，底纹保留主要通过未覆盖区域和边缘露底实现，不必把每个图章都调成看不见的低透明度。

先确定大轮廓、色彩归属、方向与露底，再生成内部笔触细节。不要先生成通用污渍包，再依赖随机着色凑出风格。

### 主色基底与相近色涂块

按材料面先确定主色，再挑选邻近的冷暖、明度和少量色相变化。灰色可以偏蓝、偏紫、偏橄榄或偏暖，但这些变化仍需属于同一个整体灰调；低饱和不等于统一去色，丰富也不等于每片涂块都换成新色系。

生成素材时将一个色系内的变化写进简报，先看整组的色彩亲缘，再看单个形状。新增素材用于选择与构图，不必在同一资产中全部使用。依据底材和参考分别制作屋面、墙面等色系，避免一套亮色笔刷覆盖所有材质。

上材质后锁定曝光和灯光，以主色是否持续可读、相近色是否有层次来判断。必要时用独立的目标色混合控制源图色彩与细小厚涂明暗，原基底仍单独保留；不要通过全局模糊或调曝光补救色系不协调。

## 形状库与方向

根据参考先准备有差异的不规则素材，再选择适合当前立面的形状；不要求把整套素材全部用在一栋建筑上。

| 形态 | 设计重点 | 常见误差 |
| --- | --- | --- |
| 偏心爆裂 | 偏置中心、几片粗大断臂、大片缺失区域 | 圆形烟花、均匀星芒、细碎飞点 |
| 断续放射 | 不等长宽笔、空缺扇区、断开的色片 | 等角度辐条或规则扇形 |
| 撕裂刮擦 | 刮刀交叠、宽色面、内部裂隙和露底 | 整齐矩形或满版细划痕 |
| 骨白破边 | 局部干擦、断裂分支、边缘宽窄变化 | 给所有墙边套同样的白框 |

这里的“爆裂／放射”描述颜料形态，不能自行转化为建筑受爆炸、弹击或辐射污染的剧情事实。若用户要求真实事件特效，应另按其范围制作。

构图中检查是否出现过长、过齐、与所有窗台平行的色条。通过旋转、改变长宽比例、偏移中心及使用真正有缺口的轮廓解决；不是给每个矩形同样旋转几度。确实需要横向擦色时仍可使用，但应有破边、起伏和间断。保留安静区域，不追求平均覆盖。

修改已经不合适的叠加时，关闭或移除对应旧层，从保留的基础材质重新安排；不能把新图章叠到旧大横条上，让其轮廓继续透出来。

## 生成笔刷源图

将用户参考作为视觉依据，同时明确源图用途：平面颜料素材／遮罩，不是带透视、窗户、灯光的建筑照片。源图只承载需要混合的笔触，不夹带建筑构件或其他叙事内容。

可按任务改写以下简报：

> 为指定建筑制作少量宽大的油画颜料簇，每簇由几笔可辨的宽刷、擦色或刮涂组成。用与基础墙漆相关的冷暖相邻色和明度差形成变化，保留厚实色面、方向性和断续露底。形状疏密不均，有长边和破边；不做满版细噪声、平均碎斑、文字或强定向厚涂高光。独立图章之间留出空间，背景为真实透明或明确可分离的遮罩底色。

不要强求无缝重复：局部图章的辨识性和尺度比通用平铺更重要。需要白色墙边时，优先检查已有源图是否合适，再决定复用或新生成。

查看实际生成结果，并检测文件通道。看起来透明的棋盘格可能已经画在 RGB 中，不能直接作为 alpha 使用。优先生成真实透明背景；否则使用另行生成的灰度遮罩，或经检查与颜料无混淆的纯色背景提取覆盖度。需要暗色颜料时不盲目用亮度抠黑。背景和边缘污染都不能进入最终基色。

## 在模型表面分层

保留原始基础贴图及输入节点。概念上，每个图章的叠加为：

`C_next = (1 - M) * C_previous + M * C_paint`

其中 `M` 同时包含笔刷覆盖、图章局部范围、目标表面区域和强度。颜色在正确的工作色彩空间混合，遮罩按数据读取。

为每个图章保留：目标对象／立面、表面中心、世界尺寸、旋转角度、颜色、强度、源图、遮罩。局部 UV、稳定对象坐标或有明确边界的投射均可；不能用屏幕坐标造成笔触随镜头滑动。

图章范围和立面区域需要分别约束，防止矩形图章背景覆盖整面墙，或跨 UV 岛污染内墙、屋顶、玻璃和无关立面。设计中的跨构件绘画与意外越界要区分。跨转角绘画应分别校准，避免拉伸；门、窗、招牌仍需清楚。

### 跨墙面、窗框与窗台连续投射

把连续笔触视为覆盖一组表面的绘画层。窗框、窗台、压条和相交外露管道与墙面共享同一中心、方向、尺寸、源图、遮罩及颜料颜色；它们的基础材料和粗糙度仍分别保留。不要在每个对象的独立UV上重新缩放同一笔触，也不要只因为窗框使用独立材质就将它排除。

优先使用建筑共同父坐标或公共投射坐标，按立面切线与高度采样，再用法向深度范围和目标材质／区域限制覆盖。正背面、侧面和斜角入口各自定义投射基准；同一构件包含多面时分别约束。用有限投射深度防止笔触贯穿到另一侧墙面。跨转角连续时应校准两侧接点和尺度。

已有流程使用世界坐标时可继续，但应说明：整体移动分层模型需同步变换投射参数，或先烘焙到UV；不能交付一个移动后颜料会游离的模型而不说明。

窗框接收笔触并不意味着玻璃和内墙也必须染色。根据当前任务选择目标表面，保留入口及标牌内容可读；没有具体叙事依据时，不借绘画添加新伤痕或线索。

浅色墙边属于局部颜料，具有中断、宽窄变化和有限位置。避免自动给所有轮廓描白边；也不把骨白设为发光材料。受潮、积尘与锈蚀若被表现为真实磨损，需要有构造或使用依据。

### 屋顶与泛水表面

正交俯视建筑中，屋顶通常占很大画面面积，应单独验收绘画组织。保留原屋面搭接、材料方向与接缝，以主色基底托住少量宽大色面，打破规则重复的条带或补丁节奏。主色与邻近色由具体屋面决定，不强制所有屋顶都用炭灰。

平屋面可使用公共XY投射，并同时限制高度与朝上法线；坡屋面使用与坡面对应的切线基准、法向深度和区域限制。笔触经过相邻低矮泛水表面时共享坐标、遮罩和颜色；不能仅按对象名为“roof”就给整根烟囱、通风帽和竖面全部染色。

为屋面与非重叠构件分别选择烘焙UV，保留原有通道，按实际显示需求分配贴图尺寸。交付说明哪些部分仍是可编辑节点、哪些沿用上一阶段烘焙结果，不把局部新增的分层文件描述成整栋每层均可编辑。

## 源文件与发布材质

分层 Blender 源文件保留原图、绘画图、混合节点和参数；关闭新增层应恢复基础外观。运行时不支持源节点时，可将合成结果烘焙为新的基色图集，另存交付版本。

仅烘焙目标材质的颜色，不把预览灯光烘进去；为 UV 岛保留适当边距。未经要求，不修改未绘画部分的几何、UV 或材质。

构件的既有UV若为重复或重叠映射，另加不重叠的烘焙通道，保留旧UV。新增通道前显式固定原贴图使用的UV，避免激活新通道时改变底纹。用于烘焙的临时网格删除非目标面后，也移除并重映射未使用材质槽，避免这些槽的活动图片意外参与烘焙或引发循环依赖。导出时检查每个基色纹理引用的 `TEXCOORD_n` 确实存在于对应网格。

glTF 的标准材质不能自动表达任意 Blender 节点。导出后实际检查纹理通道、UV、透明／粗糙度、外部依赖和法线方向。对于已有 Three.js 查看器，复用其颜色管理；替换贴图时保留 UV 通道、方向和采样变换，多版本比较使用独立材质，避免修改共享纹理污染旧版。

## 验证画面，而非只统计参数

- 固定机位并排查看基础版与叠加版，远看确认大色块，近看确认板缝、纹理与露底。
- 检查窗间、转角、墙脚及 UV 接缝，排除矩形底色、接缝污染与均匀白框。
- 同机位比较斜向笔触跨过墙面、窗台、窗框的连续性；同时核对它们的投射参数一致。材质边界不应成为绘画边界，构件自身的凹凸和光照则应继续可见。
- 同时查看分层源文件与烘焙交付近景，确认新增UV、图集边距或材质切换没有造成截断、错位或底纹丢失。
- 屋顶使用同机位前后对照检查主色、相近色色面、搭接和泛水衔接；整体取景要能看到主要屋面范围，不只展示墙面或一个局部构件。
- 用另一光向确认颜料没有自带强投影／高光。实际目标渲染器尚未验证时，只报告已验证的 Blender 渲染结果。
- 在保持几何的材质迭代中核对原几何、UV和未改材质；需要精确保留旧笔刷时可核对源文件校验值。
- 面积采样可辅助解释改动，但不能充当美术验收或精确遮罩覆盖率。
