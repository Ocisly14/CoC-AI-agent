# 分组油画笔刷阴影：Spec & Implementation Plan

日期：2026-09-08

状态：已被用户修订替代。2026-09-08 的“补满暗形 + 顺序缓存画布”实验已撤回；当前方向为沿投影方向的矩形笔带、30%–60% 随机重叠、按顺序分组叠加已有笔刷贴图。本文保留作历史讨论记录。

适用：Godot painterly 实验室与蓝鸟场景。

本次交付：仅此文档，不修改渲染代码、素材或场景默认值。

## 1. 目标与已确定的方向

让阴影呈现由人用多支油画笔逐步画成的效果：先铺成连贯暗形，再接笔、强调接触处、处理局部边缘，最后保留少量干刷变化。

已确定：

- 多个笔刷按用途编组；先选用途，再从对应组内随机选择具体笔刷。
- 随机发生在下笔时。同一笔内部通过连续曲线变化力度、倾角和转笔，保留完整笔触身份。
- 不再用固定重叠百分比排笔。笔触位置由目标暗形和已有覆盖决定。
- 大片阴影采用多笔组织；小片阴影允许一笔完成，不设统一笔数。
- 原始笔刷配方、组内用途配置、单笔随机结果分别保存。
- 同色笔触相接可以增加覆盖，不能因笔数增加而无限变黑。
- 提供「🌟 重新作画」、固定种子、分组控制与作画过程预览。
- 静止场景和相机移动不触发随机变化。动态随机不默认解释为每帧闪动。

验收画面应先读成一片阴影，近看才辨认出各笔的方向、力度与颜料差异。

## 2. 当前基线与本次替换范围

当前基线见 `godot-client/rendering/painterly/PRESSURE_STAMPS.md`：

- `cast_brush.gdshaderinc` 以固定间距排列沿投影方向的长笔。
- `procreate_brush.gdshaderinc` 使用统一压力曲线，以程序笔尖和原始颗粒连续盖印。
- 含漆量目前按归一化行程衰减；重叠量参与额外积色。
- 根部接地保护与绘画笔触分开计算；太阳遮挡进入现有合成路径。
- 现有投影使用物体包围盒代理，接收面主要为水平面。

本次替换排笔规划、用途选择、随机生命周期、含漆消耗和跨笔触合成；复用原始颗粒、笔尖计算基础、物体注册、光照发布与已有回归工具。

旧压力模式保留为对照。新模式不读取 `shadow_brush_overlap`，也不复用按重叠次数加暗的公式。

## 3. 范围与近似

### 3.1 本版包含

- 五类笔刷组，以及修边组的硬边／软扫子用途。
- 按目标覆盖规划短曲线路径，包含宽笔铺色与局部补笔。
- 压力形变、倾角、转笔、距离驱动的含漆消耗。
- 顺序绘制、有限底色带入和局部擦混近似。
- 基于世界尺度的颗粒、稳定种子、绘画版本、缓存失效管理。
- 实验室分组编辑、单笔预览、逐笔回放和场景回归。

### 3.2 明确限制

- 不复刻 Procreate 私有公式，不做逐根刷毛或完整流体／真实颜料光谱模拟。
- 不模拟跨会话干燥、干后罩染或不同投影之间的实体湿颜料交换。
- 继续使用包围盒投影代理；复杂网格准确轮廓和任意曲面接收不在本版范围内。
- 包内有 7 个配方、3 张去重 Grain，部分 Shape／Grain 只引用 Procreate 内置资源。仅使用可用原始颗粒；缺失 Shape 使用明确标记的程序笔尖，缺失 Grain 的配方不进入运行时候选。
- 程序笔尖变体属于项目适配笔刷，不标称新的原始 Procreate 笔刷。预览图不能充当 Shape。

## 4. 数据模型

以下名称为拟新增资源／记录；实现阶段可按项目命名规范调整，语义必须保留。

| 数据 | 必备内容 |
| --- | --- |
| `BrushRecipe` | 稳定 ID、来源配方 ID、原始 Grain、Shape 来源与参数、原配方元数据；只读 |
| `BrushGroupEntry` | 笔刷 ID、启用状态、选择权重、用途覆盖参数、适用宽度／长度、边缘类型 |
| `BrushGroup` | 稳定组 ID、用途、候选项、动作预设、随机幅度、重复抑制、笔数／面积预算 |
| `GesturePreset` | 力度／倾角／转笔曲线、宽度与压扁响应、含漆范围、流量响应、消耗率、带色强度 |
| `StrokeRecord` | 稳定笔触 ID、组与笔刷 ID、曲线控制点、宽度、随机结果、初始颜料、绘制序号 |
| `PaintingPlan` | 物体与接收面 ID、目标形状版本、资源版本、用户种子、绘画版本、笔触列表 |
| `PaintingCache` | 世界到画布变换、覆盖／颜料／干刷纹理、匹配的光照版本、完成状态与内存用量 |

资源在场景实例中隔离编辑。配置保存为资源；计划保存明确的单笔参数，回放不依赖重新调用全局随机数。

### 4.1 默认笔刷组

| 组 | 职责 | 动作与颜料特征 | 使用限制 |
| --- | --- | --- | --- |
| 铺色 | 构成主体暗形 | 宽扁、充足含漆、轻至中等稳定推进 | 优先保证整体覆盖，不让干刷支配主形 |
| 衔接 | 连接相邻色块、修补缺口 | 中宽、短推拉、较温和变化 | 从已有覆盖附近伸入缺口 |
| 接触 | 接地处与少量重点暗部 | 窄／短、较暗调色、明确落笔 | 仅真实贴地位置生成接地用途 |
| 修边 | 修整指定边界 | 硬边：窄侧落色；软扫：轻触少漆 | 保留硬软区别，不统一羽化全轮廓 |
| 干刷 | 少量破边、露底、纹理变化 | 低含漆、轻擦、颗粒明显 | 受面积预算限制，不破坏主要连通性 |

默认各主组配置至少两个可选的可用配方／适配变体；一个配方可以参与多个组。首轮通过单笔样张确定分组与权重，不能只按笔刷名字推断效果。UI 显示共享素材来源。

## 5. 目标暗形与笔触规划

### 5.1 目标场

以物体与接收面组成缓存单元，建立接收面局部二维坐标：

- `S(x)`：目标阴影覆盖，来自当前投影代理及已有长度限制。
- `D(x)`：到目标轮廓的有符号距离，用于候选评分和局部修边。
- `K(x)`：真实接地保护范围，复用现有几何判定；悬空物体为零。
- `Cplan(x)`：CPU 低分辨率规划覆盖近似。
- `U(x) = S(x) * (1 - Cplan(x))`：未完成区域。

目标形状先确定，再规划笔触；不得让每笔的独立长度随机把整体形状打散。允许的艺术性边缘偏移以世界距离明确限制，并服从前侧保护与原长度范围。画布包围矩形只是存储范围，不能成为可见裁边。

### 5.2 有界规划过程

1. 从 `U` 中找出最大的连续缺口，忽略小于可见阈值的纹理孔洞。
2. 根据该区域的主轴、局部边界和接收面方向，生成少量二次或三次 Bézier 候选路径；最多 8 个候选／决策。
3. 按用途筛选笔刷组和笔刷，估计覆盖收益、越界程度、转弯程度和无效重复覆盖。
4. 使用固定评分加权抽取合格候选；并列时按稳定 ID 排序，保证可复现。
5. 将预计笔尖足迹写入 `Cplan`，再次计算缺口。
6. 主体完成后依次规划衔接、接触、修边和少量干刷笔。

候选评分示意：

```text
score = 新覆盖的目标面积
      - λoutside * 越出允许边界的面积
      - λrepeat * 无效重复覆盖的面积
      - λbend * 超过动作允许范围的弯曲
```

必要的接笔重叠不受处罚；`λrepeat` 只抑制无法改善覆盖或边缘的重复。压力、笔宽和笔长约束必须在生成后再次检查。

规划网格初始最长边 128，复杂形状允许升到 256。它只估计几何覆盖，不逐笔读取 GPU 画布。GPU 真实颗粒与 CPU 估计的偏差由验收量化；必要时在一次完整绘制后做一次低分辨率审计并追加有限补笔，禁止每笔同步读回 GPU。

默认预算目标：每单元总计不超过 64 笔，其中最多 16 笔用于补缺／修整。预算不足时优先扩大铺色笔或减少装饰笔；不能以无限补笔解决失败。仍无法达到覆盖要求时记录失败，保留当前已验收模式，不悄悄用平涂替代整片油画阴影。

## 6. 分组动态随机

### 6.1 选择概率

```text
effective_weight = entry_weight * suitability * repeat_factor
probability = effective_weight / sum(effective_weights)
```

- `suitability` 包括用途、宽度、长度和硬／软边兼容性，不合格项为零。
- 最近两笔的同组笔刷获得较低权重；默认抑制系数 0.25，不是绝对禁用。
- 单候选组允许重复。空组跳过可选用途；必需铺色组为空时报告配置错误，不能随机跨组补位。
- 候选列表按稳定 ID 排序，使用独立的确定性随机流，不受其他物体绘制顺序影响。

### 6.2 随机生命周期

```text
stroke_seed = hash(user_seed, caster_id, receiver_id,
                   painting_revision, group_id, stroke_id)
```

笔刷选择、路径扰动、动作变化分别派生子种子，避免调整一种随机幅度打乱所有其他选择。资源 ID 使用可保存的稳定标识，不能使用进程实例号或内存地址。

- 下笔时选择整笔的笔刷、动作预设及随机偏差。
- 组内动作参数成套采样，再做受限扰动；不可把宽笔、极少颜料和强覆盖等互相矛盾的目标独立乱配。
- 同一笔内使用低频连续变化；不在每个 stamp 重新选笔。
- 「🌟 重新作画」递增选定对象的 `painting_revision`；提供显式的全场景重画操作。
- 保存／恢复种子、版本和计划可以复现；同设备输出允许浮点容差，不承诺不同 GPU 逐位一致。
- 自动随时间重抽不属于默认行为。本版“动态”指每次下笔产生变化，过程预览按记录回放。

## 7. 单笔盖印与颜料状态

### 7.1 手势

沿路径按弧长采样，局部切线定义笔尖朝向。盖印间距默认基础笔宽的 10%，只控制积分精度。

```text
pressure(s) = clamp(preset_curve(s / length) + smooth_variation(s))
width(s) = base_width * width_response(pressure)
tip_length(s) = base_length * squash_response(pressure, tilt)
rotation(s) = tangent_angle(s) + roll_curve(s)
```

各组具有各自的落笔／行笔／收笔曲线，不再套用全局 `0.65 → 0.9 → 0`。充分含漆的轻压允许稳定落色；接触较暗由用途颜料参数表达。允许短收笔和后笔覆盖笔尾。

笔尖轮廓沿用并扩展圆角扁笔 Shape；颗粒在独立世界尺度的稳定坐标系采样。拉长路径或压宽笔尖都不得把 Grain 拉伸。画布换分辨率不改变颗粒相位或世界尺寸。

### 7.2 含漆与积分

```text
deposit_rate = flow_response(pressure, charge, brush)
mass_i(x) = shape_i(x) * grain_contact_i(x) * deposit_rate_i * distance_weight_i
alpha_stroke(x) = 1 - exp(-sum_i mass_i(x))
charge_next = max(0, charge - estimated_deposit_volume / brush_capacity)
```

`distance_weight` 包含采样距离及接触纵向尺寸的校正。减小盖印间距不能无故增加整笔沉积或消耗。

含漆消耗在笔触生成阶段按接触面积和实际距离估计，保存每段 charge；不能把单个片元的消耗当成整支笔的总消耗。若后续取得实际沉积统计，可替换估计，但首版必须标记其近似性质。

charge 低时逐渐提高颗粒接触阈值，形成露底。长笔更可能需要结束并重新蘸色；不能把消耗恒定绑定为“整笔走完才耗固定量”。

### 7.3 顺序画布与有限湿混

画布内部存储覆盖、预乘颜料表达及干刷量。第一版颜料表达限定为当前阴影调色范围内的明度／色调参数，不宣称物理颜料混合。

```text
Anew = Astroke + Aold * (1 - Astroke)
Qnew = Astroke * Qbrush + Qold * (1 - Astroke)   # Qold 已预乘覆盖
```

同色重复覆盖趋向同一颜色；不再由 `total - strongest` 得到额外黑度。笔尖重复采样先积分为本笔 alpha，跨笔触再按绘制顺序合成。

有限湿混使用前一段接触区域的低分辨率画布估计带色，并沿笔触传播笔上颜料参数；完整分辨率 GPU 用前一完成阶段的画布做受限局部擦混。两者均为美术近似，不承诺颜料质量守恒。

带色强度取决于压力、组设置和本次作画的虚拟湿度。轻触主要落色；强擦混可以带入已有颜色。软扫仅在允许边界带内搬移少量覆盖／颜料，不得把阴影拖到前侧或产生接地漏光。

顺序合成采用离屏双缓冲，禁止在同一 pass 同时采样和写入同一纹理。不跨 GPU 绘制调用依赖未声明的先后关系。具体后端路线在 M1 原型验证后确定。

## 8. 接入、缓存与时间稳定

### 8.1 现有着色接口

- 完成画布输出明确的覆盖、用途颜料变化、干刷通道；需要色调时新增独立受限通道，不塞进旧的重叠计数含义。
- `shadow.gdshaderinc` 新模式读取缓存；`surface.gdshader` 新模式禁用基于重叠量的额外积黑，使用已合成的颜料表达。
- 太阳遮挡只在既有直接光路径计算一次；画布不能先烘焙最终暗色，再重复乘相同遮挡。
- 多个物体在同一接收点的太阳阴影先合并可见度，不能连续乘暗；颜料取稳定的主贡献或归一化混合。
- 接地保护作为独立几何安全层保留，且限制于真实接触范围；接触用途笔负责视觉重点，不能替代安全层。

### 8.2 更新策略

| 变化 | 行为 |
| --- | --- |
| 相机移动／缩放 | 保留计划和随机结果；仅按需调整采样 LOD |
| 🌟 重新作画 | 新绘画版本，重新选笔和规划 |
| 调组权重／启用笔刷 | 重建受影响对象计划；明确标记资源版本 |
| 调力度／含漆／形变 | 保留可兼容笔触身份，重新绘制；覆盖明显变化时局部补规划 |
| 光向或物体小幅变化 | 保留笔刷 ID、种子与笔序，重投影或调整路径 |
| 形状拓扑或接收面关系改变 | 重建受影响单元，其他单元不重抽 |
| 对象移除／退出范围 | 释放或回收单元，不留下旧画布 |

缓存与光照捕获使用匹配的 revision 一起发布。默认展示完成结果；分帧更新的中间画布不可意外出现在正式场景。旧完成结果只能和旧匹配快照一起使用，不能把新光向与旧投影混合。快速动态超预算时使用匹配当前快照的旧压力路径兜底，并记录次数；避免无限期冻结旧阴影。

接收高度、旋转、投影坐标系退化、近乎垂直日照均需专门处理。随机绑定物体身份，颗粒锚定接收面的世界尺度坐标，不能由相机坐标生成。

### 8.3 初始性能预算

以下是待原型验证的工程目标，不是已经测得的性能：

- 每单元最长边 512 texel 起步，支持 256–1024；优先保证世界纹理密度，超限区域分块。
- 缓存总预算 64 MiB（含持久纹理、双缓冲临时空间和 mip），实现必须计算真实占用；超预算优先回收不用的单元和降级非重点区域。
- 更新允许分帧；每帧 CPU 规划和 GPU 重画目标分别不超过 2 ms，必须分开记录，不以平均帧率代替。
- 蓝鸟同分辨率稳定场景 GPU 中位数目标不比当前压力基线增加超过 10%；更新 p95 帧间隔目标不超过 33.3 ms，并报告最坏值与发布延迟。
- 原生后端 GPU 计时不可用时记为 unavailable，不写零耗时；替代后端测试单列，不冒充原生结果。
- 预算未达成时继续优化或保留旧默认，不静默降低验收指标。

## 9. 实验室与编辑体验

- 算法对比：当前压力盖印／分组作画，同相机、同光照。
- 组列表：启用状态、候选笔刷、来源、权重、重复抑制、笔数／面积预算。
- 动作控制：预设、随机幅度、含漆、压力形变、带色／擦混强度。
- 单笔预览：压力曲线、笔尖轮廓、含漆沿程曲线，以及同路径多笔刷样张。
- 🌟 重新作画：选中对象／全部；显示当前种子与绘画版本，可复制、保存和恢复。
- 过程预览：逐笔播放、暂停、单步、选中笔触查看组／配方／随机参数。回放已记录计划，不逐帧重新规划。
- 调试视图：目标形状、未覆盖区域、按组着色、笔触路径、覆盖、颜料、干刷、接触安全层、缓存 revision 与耗时。
- 面板不再将固定重叠百分比作为新算法的艺术控制；旧模式仍可显示旧参数。

## 10. 实施计划与阶段出口

## 11. 验收标准

### 11.1 算法与随机

- 固定资源、种子、版本和几何快照时，笔刷 ID、笔序和参数一致；其他物体增删不扰动未受影响对象。
- 多次重画产生可见变化；所有选择仍在用途允许组内，权重为零的笔刷不出现。
- 最近使用抑制按条件权重生效；单候选与空组不会死循环。
- 在“覆盖已充分”的区域重复同色铺笔，归一化颜料值不因笔数额外变暗；不同色按笔序产生不同结果。
- 将采样间距从基础笔宽的 10% 改为 8%，单笔平均覆盖差目标不超过 0.01；含漆消耗差不超过 5%。
- 轻／中／重三档同笔刷测试，测量横向扩展与纵向压缩，不能只改变透明度。
- 同样初始含漆的长短路径，在共有前段行为一致，长路径后段更容易变干；Grain 世界尺度不变。

### 11.2 形状与画面

- 默认铺色配置的主体内部平均覆盖达到 0.98，排除明确的边缘带与干刷展示区域；不出现贯穿暗形的规则漏底缝。
- 沿用接地采样点无漏光、前侧无越界、悬空无接地补色、不同接收高度不串层。
- 无矩形缓存裁边、盖印断节、规则锯齿或整排重复尖尾。
- 多物体重叠时不重复乘太阳遮挡；接触安全层不会被软扫擦掉。
- 蓝鸟远看为连贯暗形，近看可识别组间差异；根部不会因每条长笔统一重压而形成周期性暗条。
- 主观画面验收使用实际 GPU 截图／视频；指标通过不能替代画面判断。

### 11.3 动态、性能与交付证据

- 固定种子下进行光向连续变化、物体移动／移除、相机缩放、接收高度变化与近垂直日照测试。
- 记录笔触身份稳定性、缓存重建次数、兜底次数、发布延迟和最坏更新帧；无随机闪烁或长期旧影。
- 同设备、同分辨率、同相机与光照，预热后至少两轮、每轮至少 120 稳定帧；动态更新另测，不混入稳定均值。
- 分开报告 CPU 规划、GPU 重画、稳定采样、帧间隔 p50／p95／最大值、缓存内存。VSync 限帧不能作为无开销证据。
- 保存新旧全景与根部近景、分组调试图、单笔样张、逐笔回放视频、机器可读报告及人工检查结论。
- 旧压力／旧颗粒路径的现有回归继续运行；新增测试重点验证可见行为、稳定性和边界条件，不复写实现公式。

## 12. 来源与设计解释

以下来源支持绘画行为概念；它们没有提供本项目的权重、力度数值、规划算法或 GPU 预算。上述数值均为工程起点，需通过样张与场景验证。

- [Procreate Brush Studio Settings](https://help.procreate.com/procreate/handbook/5.4/brushes/brush-studio-settings)：Shape／Grain 与压力、倾角等笔刷行为。
- [Gamblin：Direct Painting](https://gamblincolors.com/direct-painting/)：直接画法包含不同长短与方向的笔触；一次直接作画不等于一个阴影只有一笔。
- [Dan Scott：Painting Big, Simple Shapes and Colors](https://drawpaintacademy.com/big-simple-shapes-and-colors/)：多笔色彩变化仍服务于完整的阴影形状与一致的整体明度。
- [University of Delaware：Paint Application Principles and Techniques](https://www1.udel.edu/artfoundations/beg_painting/techniques.html)：湿画时压力影响混色与带底色；轻触、局部混合和干刷有不同用途。
- [Bill Inman：My Wet Paint Turns Muddy](https://www.masteroilpainting.com/my-wet-paint-turns-muddy/)：足量颜料、低笔角、轻压和连续一笔可以清楚落色。

最终交付包含可编辑分组资源、实现代码、原始素材来源及近似说明、实际截图／视频、性能与检查报告。切换蓝鸟默认属于 M7，本次文档提交不提前切换。
