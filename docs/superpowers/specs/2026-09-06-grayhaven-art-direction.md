# Grayhaven 艺术风格指导

> **历史版本，审美基准已被替代。** 2026-09-07 起，全项目美术制作以[叙事性油画写实美术手册](../../art-direction/README.md)为准：巡回画派的现实底色＋《极乐迪斯科》的表现性笔触。本文保留既有构造研究、素材研究和技术记录，涉及粉蜡笔感与《奇异人生》主参考的建议不再作为新资产验收标准。新交付为设计规范与视觉样板，不代表运行时已完成改造。

日期：2026-09-06 · 版本：1.0 · 范围：全局沙盘与后续共用视觉语言

**目标：把灰港画成一座能够缓慢呼吸的海岸小镇。保持可信的空间和建筑比例，以低饱和的大色块、干性笔触和有色光影组织画面，让文字成为故事的主要载体。**

本文以 **2015 年初代《Life is Strange》** 为主要参考。续作、重制版、宣传插画与粉丝滤镜截图不混用为同一套画面标准。Grayhaven 保留自己的 1985 年北加州背景和现有地图框架；这是一份制作指导，文中建议尚未全部实现。

## 1. 如何理解“低饱和蜡笔画”

这个描述准确抓住了柔和、略带粉质、表面不光滑的感受。制作时可将目标命名为 **“带粉蜡笔触感的手绘写实”**。这里的“粉蜡笔触感”是本项目的审美选择，不能当作原作使用实体蜡笔或特定蜡笔着色器的事实。

原作主创提供了更精确的依据：Michel Koch 回顾初代时，将其描述为写实比例与简化纹理之间的平衡，使用了 *impressionistic realism* 一词，强调画面整体的光、色与情绪。[Michel Koch 访谈，GamingTrend，2019-12-14](https://gamingtrend.com/interviews/we-interviewed-michel-koch-co-creative-director-on-life-is-strange-2/)

概念艺术家 Edouard Caplain 则说明，团队希望实现 *animated concept art*；三维要承接概念画的表现方式，而不只是复现画里的物件。其访谈提到手绘处理、暖夕照与偏蓝暗调，以及先解决主要形体和光色、最后添加细节的流程。[Edouard Caplain 访谈，80 Level，2016-03-03](https://80.lv/articles/life-is-strange-concept-artist-talks-about-art)

据此，本项目采用以下区分：

| 用户感受到的特征 | 转译为制作要求 | 容易走偏的做法 |
| --- | --- | --- |
| 低饱和 | 环境颜色彼此协调，保留少量醒目的局部颜色 | 全画面统一去色，天空、树、建筑都变成灰褐色 |
| 蜡笔／粉彩感 | 不完全均匀的填色、干笔断续、较大的色面与少量露底 | 给整张屏幕铺密集噪点或交叉排线 |
| 柔和 | 大范围光色过渡、柔化远景、选择性弱化边缘 | 模糊整个世界，让路口与建筑轮廓难以识别 |
| 怀旧 | 材料褪色、局部修补、生活使用痕迹、安静的构图 | 统一泛黄、厚暗角、到处做旧 |
| 简化写实 | 保留结构与比例，删去低收益细节 | 用一模一样的圆锥树与彩色方盒代替所有对象 |

**推荐关键词**：手绘写实、干性笔触、粉质色面、褪色木漆、有色阴影、海岸空气感、克制的暖光、生活痕迹。

## 3. Grayhaven 的视觉基调

**盛夏的海岸有潮气，旧木屋还有人住，远山里的设施安静得有些疏离。**

年代、地点和衰退中的渔业／伐木业来自 [Grayhaven 模组设定](../../../testmods/grayhaven/DESIGN.md)。原作的秋日情绪可以借鉴，但灰港的七月不应因此铺满橙色落叶。这里以常绿红杉、干草与湿地的反差、盐蚀墙面和旧铺面表现时间感。

整张地图优先建立四块视觉关系：

1. **海面**：冷而开阔，提供最长的视觉停顿。
2. **小镇**：暖灰、米白和褪色木漆，形状密集但颜色有秩序。
3. **林地**：层叠的灰绿、蓝绿和深色空隙，围合道路与空地。
4. **远山设施**：较冷、较整齐，靠布局差异形成距离感。

不使用持续红光、诡异粒子或异常色带替地点提前作剧情判断。气氛可以含蓄，事件表现需要后续有效状态驱动。

## 4. 色彩与明度

### 4.1 起始色板

以下为 **Grayhaven 原创调色起点**，不是原作取样色板。HEX 表示供美术沟通的 sRGB 颜色；屏幕最终颜色还会受光照、雾、曝光和色调映射影响。

| 名称 | 色值 | 主要用途 |
| --- | --- | --- |
| 纸白 | `#E4DDCB` | 阅读背景、灯塔受光面的方向 |
| 旧奶油漆 | `#C5BDA5` | 建筑基色 |
| 漂流木灰 | `#8B8475` | 码头、木墙、旧路边构件 |
| 褪色灰蓝 | `#819496` | 少量民居、旅馆立面 |
| 海雾灰 | `#B3BDB9` | 雾与远景调色方向 |
| 海面蓝绿 | `#657E83` | 海水中间色 |
| 鼠尾草绿 | `#8C947A` | 草地、林缘亮部 |
| 林冠灰绿 | `#607766` | 林地主要色面 |
| 林间蓝绿 | `#3F5552` | 林地暗面与缝隙 |
| 冷影灰紫 | `#656776` | 阴影偏色的参照 |
| 旧砖锈红 | `#A66F58` | 屋顶、锯木厂、小面积路标 |
| 温暖琥珀 | `#DCB17B` | 夕照与少量灯光 |

用色板建立亲缘关系，不要求对象只使用这十二个颜色，也不要直接把“纸白”当作白色发光材质。

### 4.2 颜色分配

以默认全景作为判断对象：大面积属于冷暖灰与自然色，辅助色集中在街区和少数地标，最醒目的颜色仅占小面积。可用 **约 70% 环境基调、25% 辅助色、5% 强调色** 作第一张色稿的构图练习；这不是运行时像素配额。

降低饱和度时保留色相差：暖灰墙面、偏紫阴影、蓝绿海水不能都落入同一种军绿色。夕阳可以让朝光面变暖，背光面继续保留天空的冷色。

### 4.3 明度层级

全景先读出海岸轮廓、小镇与森林，再读出灯塔、码头和道路。深色林隙、屋檐与建筑接地处提供重量；大面积崖壁不应成为连续的近黑色切面。

在小尺寸灰度图中检查三件事：海陆分离、建筑不淹没在林冠中、地标有可读剪影。整体柔和可以保留，关键局部仍需有足够对比。

## 5. 笔触：把“蜡笔感”落实到表面

### 5.1 三层组织

| 层级 | 应绘制的内容 | 全景中的作用 |
| --- | --- | --- |
| 大色面 | 一片林冠、一段屋顶、湿岸与干坡的分区 | 缩到小图仍能看到的主要关系 |
| 中尺度笔触 | 顺坡擦色、树冠亮斑、旧漆补色、岩层转折 | 给表面方向与手工感 |
| 细颗粒 | 少量干笔露底、轻微纸齿般的不均匀 | 近一点才察觉，远处自然消失 |

默认视距应主要看到前两层。若第一眼看到满屏砂点、噪声或重复纹理，说明细颗粒抢占了画面。

### 5.2 笔触要跟随对象

- 木板沿板材方向留下断续擦痕；转角、补漆和受潮处改变色面。
- 崖壁按岩层或地形转折成块，裂纹只保留少量方向线。
- 草坡用成片灰绿与枯黄交接，避免每平方米都覆盖同密度短线。
- 树冠的亮斑随枝叶团块分布，不沿每片三角面均匀描亮边。
- 海面以较长、较平缓的横向色带组织，亮斑断开，避免棋盘式波纹。

笔触应附着于模型／地表坐标。平移镜头时不能像屏幕上的贴纸一样滑过房屋。纸感可以极轻地存在于阅读卡片；世界的绘画感优先来自物体自身。

### 5.3 一块木墙的制作例子

先铺褪色灰蓝底色；用两三片相邻色表现日晒与补漆；在部分板缝补暗线，门框保留较清楚边界；最后只在少数板面加入干笔断口。缩回全景后，首先读到一块旧灰蓝墙面，而非密密麻麻的木纹。

材质里可以保留轻微的局部遮蔽与磨损。不要把强烈夕阳高光和长投影固定画入基础颜色，否则切换蓝调时物件会仍然“自带日落”。

## 6. 形体与边缘

### 6.1 建筑

保留可信的层高、屋顶坡度、檐口与街道关系。差异主要来自长宽比例、屋顶类型、店面假立面、少量附属体块和褪色漆面，而非每栋房屋换一个随机颜色。

优先补能在全景留下剪影的变化：旅馆的长条屋顶、锯木厂的大跨度棚顶、灯塔的细长塔身、主街的连续立面。主街可保留窗套、上下推拉窗的一条中横档及大橱窗立柱；细密窗格和室内陈设继续省略，白天不要整排发光。

#### 主街材质与构造补充（2026-09-06）

**先成立为北加州木构商业街，再做低饱和手绘处理。** 模组中的假立面、楼上住处、封板橱窗，不能被统一的粗木块或石瓦贴图替代。

- 外墙以涂漆横向搭接挂板为主，后厨附属墙可用竖板压条；窗套、转角板和檐口是独立的平滑油漆木构件，不复用大块墙面木纹。各建筑按统一世界尺寸铺图，横板不能随层高变宽，也不能在相邻楼层突然断行。
- 坡屋顶区分小片木瓦与镀锌波纹铁皮；平顶用暗色卷材。木瓦逐行搭接，金属波纹沿坡向排水，竖直山墙仍用墙面挂板。孟多西诺当地历史材料记录了早期木瓦屋顶以及约 1890 年开始出现的波纹铁皮，提供北加州海岸的地域参照。[Kelley House Museum](https://www.kelleyhousemuseum.org/building-mendocino-tin-roofs-2/)
- 店面按基座、橱窗下护墙、大玻璃、上亮窗、招牌和檐口组织；门口用较深的门洞色与凸出的窗套表达退进关系。楼上用较窄的住宅窗；封店使用失去油漆的灰木封板。这个构造顺序参考历史店面保护资料，而非随意添加复古饰件。[NPS Preservation Brief 11](https://home.nps.gov/orgs/1739/upload/preservation-brief-11-storefronts.pdf)
- 基座采用克制的灰白混凝土色，不套海岸岩石纹理；玻璃有暗部和宽阔的天空反射，诊所入口保留磨砂效果。木漆、金属、木瓦与玻璃分别响应光照，不能统一处理成粗糙蜡块。

具体屋面材料分配、板材尺寸、漆色和后立面开窗均为美术解释，并非模组的建筑测绘数据。当前仅制作最外层 LOD 外壳，不增加室内空间；贴图细节随缩小由 mipmap 自然合并。

### 6.2 红杉林

概览树形采用窄高、较丰满及轻微偏冠的少量预制变体，共用手绘色面和材质。轮廓以中下部活树冠最宽、向顶端逐渐收窄为主；上部枝条更短，底部保留少量裸干，避免顶端横向大枝和长秃杆造成头重脚轻。通过不等距枝层、局部缺口和轻微不对称保持自然感，不画成规则圆锥或层层等宽的圣诞树。断梢、伞状树冠不进入当前通用树林池。这是本沙盘的剪影取舍，不代表所有树龄红杉的生长形态。

远景先组织 **林冠群落、明暗团块、空地和穿行通道**，只在林缘与关键剪影处露出单树。树木位置应呈群聚、疏密和空缺；增加随机旋转不足以解决均匀撒点的人工感。

锯木厂的巨杉另按用户提供的仰视实拍照片处理：长而笔直的主干贯穿约下方三分之二，树冠集中在高处，整体高耸；不沿用普通树从下至上的密集枝层。沙盘中转换为完整立姿，不复制照片的仰视透视和雪景。用少量静态、实例化的圆柱状树干配高位树冠贴片，明确纵向比例与真实侧面受光；树皮仍用开发时生成的专用素材。

### 6.3 海岸与道路

海岸由较大崖面、局部缓坡、石滩和空水面组成，避免全长同高度切边或整齐的一圈碎石。码头向海面形成明确的水平形状；灯塔立于有留白的陆地剪影上，两者在默认镜头下需要分开辨认。

道路是嵌入地形的颜色与结构变化。主街应清楚，林径较弱；边缘宽窄与草地交接可以变化。常态下不把所有小路都画成同亮度的浅色电路图，道路高亮仍作为按需导航层。

### 6.4 边缘分工

| 边缘 | 处理 |
| --- | --- |
| 灯塔轮廓、主要屋檐、重要路口 | 相对清楚，承担识别 |
| 林内树冠、草坡与土色交界 | 局部融合，减少碎裂 |
| 远山、海雾中的林缘 | 降低对比，允许轮廓消失 |
| 地点文字与操作按钮 | 保持清晰，不进入模糊或颗粒后处理 |

不添加全局黑描边。柔硬边缘的区别由色面、材质与光影共同形成。

## 7. 光照、雾与动态

### 7.1 三个视觉预设

| 预设 | 明亮区域 | 暗部与空气 | 验收重点 |
| --- | --- | --- | --- |
| 海雾午后，默认 | 米白、淡稻草色，有方向的柔光 | 灰蓝天空光、层次清楚的林地 | 道路可读，画面不黄、不闷 |
| 迟暮夕照 | 琥珀与旧桃色集中在朝光面 | 灰紫／蓝绿背光面，较长投影 | 有明显冷暖关系，海面不变金属金色 |
| 入夜蓝调 | 少量窗光与灯塔亮点 | 蓝灰环境，地标仍可辨 | 夜色成立，但不靠全屏提亮补可读性 |

这些预设是画面样板，暂不代表模拟器的真实时间与天气。海雾也不自动赋予未知地点任何已发生事件。

### 7.2 光照原则

先用一个主要光向建立体积，再用天空与地面反射色托住暗部。阴影柔软，但在建筑底部仍有接触关系；先消除漂浮和硬黑切面，再考虑发光、光束或镜头效果。

柔光不等于所有材质高粗糙度后再把环境光加满。木头、漆面、玻璃、水面仍应有不同响应；高光数量少、形状宽、亮度受控。大范围泛光会把笔触和建筑立面一起抹掉，应最后调。

### 7.3 雾的空间逻辑

近处保留材质，中景减少细节，远景向空气颜色靠拢。海岸与低洼处可以更含混，近处主街保持清晰。全局距离雾可作起点，后续按实际收益加入少量局部雾层；不预设一定要做体积雾。

禁止用整屏灰色蒙版承担全部空气感。它只能降低对比，不能替代海、镇、林、山之间的空间层次。

### 7.4 动态强度

只保留低频、低幅度的水面流动和少量树冠摆动。默认全景不持续飘满粒子，不自动推拉镜头。关闭装饰动画后，静帧仍应成立；动效只增加生命感。减少动态效果偏好下停用装饰运动。

## 8. 把第三人称参考转成全局沙盘

原作截图的情绪往往围绕人物视线和局部空间。Grayhaven 当前需要总览，不能照搬近景的浅景深、镜头耀斑和遮挡方式。

**保持用户已经认可的地图框架与默认浏览方式。** 先通过材质、林群组织、冷暖和地标剪影改善风格；不把更换镜头、重排道路或制作室内设为美术改进的前提。

- 默认全景保留较大安静海面，城镇密集区与森林形成不同节奏。
- 陆地进入屏幕边缘时保持自然延续，避免展示悬浮棋盘的直线截面。
- 放大后增加可读的表面色块与少数形体，不随缩放突然出现全新的绘画尺度。
- 默认关闭强景深；借层次雾与细节减少处理远景。浅景深容易强化微缩模型感，也会损害地图阅读。
- 地标识别不能完全依靠标签。关闭标签仍应能指出小镇、码头、灯塔和山地设施。

未来可沿用已经讨论的 LOD：远景显示群落和建筑整体，中景显示预制形体，进入局部后再读取更细的手绘材质。当前阶段只落实全景要求，不顺带扩大到局部场景制作。

## 9. 文字、角色与状态图标

阅读层用暖纸白、深灰绿正文和少量旧墨色线条。装饰字体只用于短标题；中文长文使用稳定、清楚的正文排版。手写感不通过降低字号、模糊文字或给每个字加纹理实现。

地点标签颜色要弱于当前阅读重点，选中时提供克制的暖色提示。地图绘画处理只作用于三维画面，不能影响 React DOM 的文本清晰度。

角色仍属后续范围：优先自然比例的简化剪影、少量服装色块和固定预制动作，不以写实皮肤、毛发或大量表情动画作为门槛。

此前约定的 emoji／effect 映射继续有效。未来展示层可将同一稳定 effect 映射为统一绘制的火焰、情绪气泡或睡眠标记，避免不同平台 emoji 的高饱和与光泽破坏风格。开发阶段允许直接显示 emoji；图标只表现有效外显状态，不推断角色内心，也不新增模型调用。

## 10. Three.js 中的落地方式

这一节是本项目的实现建议，不是对原作引擎的复原。现有 [GrayhavenWorld.ts](../../../client/src/observer/grayhaven/GrayhavenWorld.ts) 可继续承载原型，无需先更换框架。

| 层面 | 建议 | 先验证什么 |
| --- | --- | --- |
| 基础颜色 | 少量手绘材质图集，配合顶点色／实例色作局部变化 | 关闭装饰后处理后，仍能看出色面与笔触 |
| 几何 | 少量建筑与树形变体，实例化复用；轮廓有意设计 | 默认尺寸下摆脱圆锥和积木的重复节奏 |
| 表面响应 | 保留现有常规材质起步；非金属哑光表面可试 roughness 0.8–1.0、metalness 0；水和玻璃单独调 | 材质有区分，墙面不泛塑料高光 |
| 阴影 | 软阴影和轻接触暗部，优先检查建筑接地 | 屋檐和树根不悬空，崖壁不成黑带 |
| 海面 | 低对比、低频色带与稀疏亮斑 | 缩放和运动时无棋盘、摩尔纹或闪烁 |
| 雾 | 距离雾起步，有必要才添加局部层 | 远处退后，近处不蒙灰 |
| 后处理 | 先锁定曝光与色调映射，最后微调分色和少量泛光 | 不靠滤镜补救错误材质，不让文字受影响 |

上述数值仅为哑光非金属材质试验起点，不适用于所有物件，也不是“原作参数”。对当前版本材质属性的解释以仓库依赖源码为准。

颜色链路先校准：颜色贴图按其实际编码声明颜色空间，法线与粗糙度等数据纹理不按颜色贴图处理，照明在工作颜色空间计算，最终正确转换为显示颜色。重复转换可能造成颜色过暗或发灰，不能用曝光不断补偿。[Three.js Color Management](https://threejs.org/manual/en/color-management.html)

程序生成可以辅助铺色和制作纹理，但需要有方向、区域掩码和尺度控制。当前 `paintTexture()` 的均匀随机短笔划可以保留作底层试验，不应继续承担整张地图的主要绘画风格。也不优先加入全屏油画／蜡笔滤镜；它们若无法在运动中保持稳定，应放弃。

所有资产在开发期制作、进入页面时加载。运行时继续复用预制内容，只修改已有状态表现，不逐拍生成纹理、模型或布景。

## 11. 对当前原型的具体改进顺序

这一判断基于已查看的全景、码头放大截图及当前实现。地图结构已经可用，主要差距是重复形体、表面语言和明暗组织。

| 优先级 | 当前表现 | 改进目标 | 暂不增加 |
| --- | --- | --- | --- |
| P0 | 林木主要是密集重复圆锥，轮廓碎而均匀 | 先做成片林冠与空隙，再补少量不规则单树剪影 | 更多树的数量 |
| P0 | 地面细纹覆盖广，近看像均匀铺设的噪声 | 大块坡地／湿岸／干草颜色，少量顺地形笔触 | 更高频程序纹理 |
| P0 | 屋顶和墙面较像干净色盒 | 手绘明暗色面、褪色和少量剪影差异 | 室内陈设与精细窗格 |
| P1 | 海崖暗面容易连成黑色切边 | 有色暗面、局部缓坡和海滩过渡 | 整圈等密度碎石 |
| P1 | 地标较依赖文字，码头与灯塔投影邻近 | 局部剪影留白、材质区分与必要的小幅布景调整 | 改写节点和道路关系 |
| P1 | 光照预设已有，但材质与照明尚未形成统一样板 | 固定一套午后基准，再从同一套材质调夕照与蓝调 | 三套互不一致的资产 |
| P2 | 界面能读但与画面仍可进一步协调 | 克制纸感、标注主次、减少无关装饰 | 大面积屏幕颗粒与花体正文 |

## 12. 制作流程与验收

### 12.1 先做一个可比较的样板

1. 固定默认镜头和午后预设，记录当前截图；地图布局、时间和缩放保持一致。
2. 对“主街—海岸—一片林地”的同一视角做一张色稿，先确定大块明暗与冷暖。
3. 制作最少样本：一面木墙、一片屋顶、一块坡地、一组林冠、一段崖壁和一片海面。先在同一张画面中协调，再推广全图。
4. 用现有三维结构验证这些样本。若像素颗粒、树形或海面不合适，在样板内解决。
5. 午后成立后再调落日、蓝调与高雾；最后添加低幅度动态。

每轮只改变一类主要问题，保留同机位对比。这样可以知道改善来自哪里，也能避免反复调色掩盖几何和布局问题。

### 12.2 艺术验收

| 检查 | 通过标准 |
| --- | --- |
| 小图检查 | 把全景缩至约 320 px 宽，海、镇、林仍是不同大块，地标没有全靠标签维持 |
| 灰度检查 | 小镇与林地可分，海岸轮廓可读，阴影不是连续黑墙 |
| 笔触检查 | 正常全景看到色面，放大才看见干笔；没有全屏同密度砂点 |
| 运动检查 | 平移和缩放时材质附着于物体，无纹理游动、闪烁或明显 LOD 跳变 |
| 光照检查 | 三个预设保持相同材质身份，冷暖改变可信，白天窗户不整排发光 |
| 阅读检查 | 打开地点手记后，文字清晰，背后动效不持续争夺注意力 |
| 去装饰检查 | 关闭标签、粒子、泛光后，地标与绘画语言仍然成立 |
| 范围检查 | 没有为了美术样板增加室内建模、实时美术生成或新的模拟事实 |

### 12.3 工程验收

在实际目标设备记录默认全景与放大状态的帧时间、显存／纹理占用和载入时间，先与当前原型比较；不预先宣称尚未测量的帧率。优先复用图集、实例化和稳定的预制资产。WebGL 降级后的文字目录仍应可用。

## 13. 可复用美术简报

> 为 1985 年北加州海岸小镇 Grayhaven 制作全局沙盘环境。空间与建筑比例可信，以低至中饱和的自然色、粉质大色面和顺物体结构的干性笔触表现材料。海水偏蓝绿，建筑以旧奶油漆、漂流木灰和褪色灰蓝为主，少量锈红与琥珀光提供焦点。森林由疏密变化的林冠群落组成，地标轮廓清楚，远景融入有色海雾。整体安静、有人生活、有时间痕迹。纹理与形体在开发期预制，当前只制作户外整体，不增加室内细节。画面为文字阅读提供定位与氛围。

**退回重做的信号**：全图军绿色、每个物体都有同样的噪点、密集玩具圆锥树、塑料高光、黑色海崖切边、强移轴模糊、全局描边、耀眼状态贴纸，或必须堆叠多层滤镜才能看出风格。
