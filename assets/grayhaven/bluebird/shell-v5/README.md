## 绘画处理

29 簇大色块主要放在窗间实墙、二楼侧墙和局部墙裙。笔触簇约 0.5–3.2 米宽，宽簇内包含少数大笔触；以灰绿、灰紫、灰蓝绿、暖赭和暖灰形成同色系里的冷暖及明度变化。中心可以明显遮盖部分旧漆，边缘保留断续刷痕。色块之间继续显示原木纹、板缝与细小修补。

20 处骨白边缘放置复用 v2 的 `ground-brush.png` 和 `ground-weather.png` 原始字节。旧图中的白色在本轮作为骨白颜料的覆盖遮罩使用，颜色为 `#EAE3CE`；它们不再只服务于暗色气候磨损。重点放置在部分转角、墙脚和窗边，不形成全楼统一白框。

每个图章都有独立中心、尺寸、方向、色系和强度，并受自身范围及立面 UV 区域的双重限制。底层原材质不作整体调色。新的彩色笔刷以纯黑表示零覆盖背景，黑底不进入建筑颜色；源图色彩与同色系平色混合以减弱微小厚涂高光，不生成法线或方向性阴影贴图。

## 保留与输出

v4 全部 83 个建筑对象、56,034 个三角形及 UV 完整保留。门头、漆字、门窗套、水管、雨棚、屋顶与室内沿用原材质。本轮只输出一楼和二楼两张新的 4K 基色图；可编辑分层文件保留所有九张原始打包图片和原材质输入，发布文件用新墙面图集替代两张旧图集。

网页复用 v3 建筑及 v4 外部构件，只为新版墙面替换两张图集。新版材质独立复制，切回旧版时不会污染原纹理；保持原贴图通道、方向及采样变换。图集、模型与实际 Cycles 渲染属于本轮交付，没有增加几何贴花或全屏滤镜。

检查覆盖几何／UV 保留、原始图片保留、旧白色笔刷复用、自包含导出和浏览器材质切换逻辑。表面变化统计采用多边形中心采样并按面积加权，仅表示可见颜色变化的估计，不等于精确遮罩覆盖率，也不是绘画质量评分。

## 制作源

`source/paint_large.py` 从 v4 构建可编辑材质并烘焙，`source/render_paint.py` 输出对照图，`source/check_paint.py` 核对交付。新彩色笔刷由 imagegen 根据用户图生成；首次输出含棋盘背景，未使用，最终通过 imagegen 改为纯黑背景，实际使用文件为 `layers/broad-pigment-black.png`。

原稿 `layers/broad-pigment-atlas.png` 只保留制作记录，不用于模型或远程预览。用户原参考图仅保存在本地 `source/user-brush-reference.jpg`。
