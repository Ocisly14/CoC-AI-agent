# 不规则油画颜料素材库 · v1

用于 Bluebird / Grayhaven 的局部墙面绘画补充。2026-09-07。包含4张原创源图集、16个独立可调用的 Blender 节点组，以及实际材质测试渲染。本轮只制作素材库，尚未把这16个新形状应用到餐厅，也未托管。

## 在 Blender 使用

1. 通过 File → Append 从材质库的 `NodeTree` 追加所需 `PFX_*` 组，也可以直接打开材质库查看测试平面。
2. 把既有基础颜色输入接到 `Base Color`，对象的局部表面UV接到 `Surface UV`，组的 `Color` 输出接回材质基色。
3. `Center`、`Size` 控制UV中的图章位置与覆盖范围；`Angle` 为弧度。将UV尺寸换算成实际墙面尺寸，建议从约0.6–2.8米的宽度试起，再以参考和镜头判定。
4. `Strength` 控制覆盖，`Tint` 与 `Tint Mix` 控制相邻色及内部纹理强度；不要给所有色块套同一个颜色。`Mask` 输出可用于局部粗糙度混合，但不默认制造表面凹凸或发光。
5. 用于单独立面材质或另加立面遮罩，避免跨UV岛污染相邻墙面。多个组可以串接，每一步的输出成为下一步基础色。

**源PNG是RGB黑底图集，不是真透明PNG，不能直接接到整面墙基色。** 节点组从线性颜色亮度计算覆盖度：低于0.015为零，0.09及以上为实盖，再乘图章边界与强度。纯黑部分恢复基础颜色。该阈值适用于本包明亮颜料，不适用于任意深色图章。4张图均由内置 image_gen 生成，未提取游戏贴图。

源图有少量生成的厚涂明暗，默认45%的同色系平色混合使其更克制；没有将这些明暗转换为法线。需要更平面时提高 `Tint Mix`，需要保留更丰富色差时降低。调试时保持光照与曝光固定。

将材质导出到不支持这些Blender节点的渲染器前，需要烘焙合成基色；也可在现有 Three.js 材质补丁中复现UV采样、边界和覆盖混合。本包交付已验证Blender节点与渲染，没有宣称已经完成Three.js接入。

## 构图使用原则

这些“爆裂／放射”指颜料形态，不表示剧情中的爆炸、弹痕或辐射事件。先把大片实墙划分为安静区与绘画区，再安排少量主形状；保留缺口、偏心和不均匀节奏。避免规律旋转复制成烟花、把笔触缩成碎噪声，或把整栋建筑铺满。白色破边只在选定墙角和墙脚出现。

## 研究依据：原作事实与本项目推导

以下为开发团队的一手日志，查阅于2026-09-07；它们记录开发阶段方法，不保证每个最终场景均使用完全相同实现。

- Aleksander Rostov，[Gorgeous ground](https://discoelysium.com/devblog/2016/03/29/gorgeous-ground)，2016-03-29：Blender生成背景底稿，遮罩混合不同表面细节，随后仍有绘画加工。这支持“结构／材料底层与绘画层分开”的制作选择。
- Jaagup Irve，[Tiling of the World](https://discoelysium.com/devblog/2016/08/18/tiling-of-the-world)，2016-08-18：从草图、粗体块到渲染；绘制后的正交图块通过投影UV与简化三维几何对应，配合深度遮挡和动态光照。因此不能把原作概括为在普通完整三维模型上加一个油画滤镜。
- Markus Härma，[From Render to Paintover](https://discoelysium.com/devblog/2019/01/23/from-render-to-paintover)，2019-01-23：手绘背景与实时物件结合；海水使用高度信息、叠层颜色、流动图和透明手绘平面，区域经过人工构图。它证明分层绘画素材可与实时表现结合，但未说明用户截图中的每片墙漆对应哪张贴图。

本包四类形状来自对用户截图和绘画需求的视觉解读，不是官方笔刷名称，也没有证据证明原作墙面使用这套节点。我们保留项目现有可剖视三维建筑，采用局部表面叠加／后续烘焙来承接画面语言；这是本项目适配方案。
