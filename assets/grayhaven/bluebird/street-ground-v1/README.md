# 蓝鸟餐厅周边 · 主街地表 v1

本轮按“直接生成一张大的街道贴图”交付连续地表底色：旧沥青、褪色双黄线、开裂混凝土人行道、路缘排水、局部修补和少量杂草。以克制油画笔触描绘材料，保留冷灰道路与暖灰铺装的区别。图片不含建筑、人物、独立道具或日照长投影。

- [最终底色 PNG](bluebird-street-basecolor.png)：原生 **1536×1024**，sRGB，整张使用，不循环平铺。内置图像工具未返回提示词请求的 3072×2048；没有插值放大冒充更高分辨率。
- [配套地面 OBJ](bluebird-street-ground.obj) 与 [MTL](bluebird-street-ground.mtl)：48×32 米，+Y 向上，10 个三角形；人行道高 0.18 米，路缘用过渡面表达。导入时保留三个文件相对位置。
- [元数据](manifest.json)：实际像素边界、米制覆盖、坐标、来源、限制与文件摘要。
- [首次生成提示词](source/generation-prompt.txt) 与 [材质修订提示词](source/refinement-prompt.txt)：使用内置 image_gen，先生成布局，再削弱照片式颗粒、加强材料绘画。

## 模组依据

`ROAD_main_street` 明确蓝鸟位于主街北半，杂货店兼邮局在隔壁，警长办公室在对面。餐厅长椅、邮筒、公告栏、电话亭和下垂电线应作为后续独立场景物件；没有画死在地面上。贴图上侧中央给现有蓝鸟建筑预留约 12×10 米落位面，邻近地块用于既有商铺落位，不表示模组中这些房屋被拆除。

`SCN_main_south`、`ROAD_dock_slope` 与 `ROAD_backstreet` 把码头坡道和后巷放在主街南端，本地块未把它们搬到餐厅旁。餐厅右侧仅是行人铺装，没有新增一条模组车行路。

## 使用与范围

尺寸均为美术推定。生成结果没有精确遵循提示词中的纵向百分比；配套网格按最终图中实际路缘位置制作。道路净宽约 9.6 米。图像顶部对应网格 −Z；蓝鸟落位面约为 X −6.2 至 5.8、Z −5 至 5，适合对照现有米制餐厅外壳。正式放置还需检查门槛和倒角。

本图是街区视距的地表基础层，约 32 px/m；人物脚边特写需要后续细节材质。基色使用 sRGB，推荐 mipmap 与各向异性过滤；无平铺需求。可从粗糙度常量 0.9 起步，排水金属如需近景应独立建模、赋材质。不从绘画颜色推算法线或高度。

已接入默认 Godot 街角 demo 的 `Streets/PaintedStreetGround`，替换旧程序道路、人行道与重复标线。餐厅保持原变换，门槛与 0.18 米铺装接地。Godot 导入保持原生尺寸并启用 mipmap，常规材质与油画适配均使用不循环采样。

已在 Godot 4.7.2 / Forward+ / Apple M5 实际渲染验证：UV 方向、朝上法线、米制尺寸、纹理与笔刷阴影传递、点击餐厅、镜头缩放／平移／复位以及晴天／暮色切换均通过。[验证报告](../../../../godot-client/demos/bluebird/qa/street-ground/validation.json)与同目录截图记录本轮接入；未验证 Compatibility 和性能预算，不包含邻居建筑、独立道具、碰撞或导航。
