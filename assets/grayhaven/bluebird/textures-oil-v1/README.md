## 依据及优先级

用户本轮明确要求的粗笔刷油画效果、用户提供的 `design-v3/primary-reference.png`，以及[2026-09-06 指导](../../../../docs/superpowers/specs/2026-09-06-grayhaven-art-direction.md)中仍有效的构造、方向与尺度要求。该文件开头已将审美标准转交给[油画美术手册](../../../../docs/art-direction/README.md)。本轮遵循这个替代关系，保留最新设计中的大一楼、小二楼和街角入口。

## 从画面成因出发

1. **油画感来自选择和落笔。** 原图并非每平方厘米都完成到同一程度。这里先安排连续的主色面，再用宽扁、断端、少量露底的笔触改变局部色相与边缘。缩小后首先看到灰白、蓝绿、锈褐、炭灰的关系。
2. **材料身份来自结构与方向。** 外墙横向挂板，墙裙竖板，雨棚向下排水，地板沿木板擦色；窗套是独立平整构件。不能用一张木纹承担所有木构。
3. **磨损来自作用位置。** 墙裙底端受街面溅水，门窗套边缘与底部磨损，吧台前沿反复擦拭，座面中心长期接触。大片完整色面与局部磨损共同说明仍在使用的餐厅。
4. **色块不等于凹凸。** 蓝紫和赭色是绘画中的邻接色，不自动代表坑洞或凸起。基色不转高度、不自动生成法线；板厚、门框退进、雨棚折边和坐垫轮廓由几何处理。
5. **笔触不能被铺图缩没。** 贴图按指定覆盖范围配置 UV。需要覆盖更大表面时，优先在真实板缝、转角、构件边缘拆分，增加独立绘制区域；不要把整张图高频 Repeat。

## 在 Blender 使用

打开 `bluebird_oil_materials.blend` 查看材质；或通过 File → Append 进入该文件的 Material，选择 `BB_OIL_` 开头的材质。十种材质已标记为资产、保留 Fake User，PNG 已打包到文件中。也可从独立 PNG 手动接入。

- Image Texture 的颜色空间为 **sRGB**，接 Principled BSDF 的 Base Color；UV 层名为 `UVMap`，使用完整 0–1 范围。
- Image Texture 使用 Linear 与 Extend。Extend 只是避免越界重复；UV 应留在 0–1 内，不靠越界拉长像素覆盖模型。
- Roughness 使用表内起点，Metallic 为 0。雨棚贴图表现的是覆盖表面的漆与氧化层；未来裸露金属区域需另做材质分区，不能把整张锈面设为金属。
- 库内相机下方是等大的方形对照片，便于比较笔触与颜色；右侧 x ≥ 20 m 有按实际建议尺寸制作的平面，供核对 UV 长宽比和笔触尺度。
- 墙裙 PNG 底部要对应模型墙脚。吧台 PNG 底部对应靠客人的前沿。不要为制造“变化”把有方向性的磨损随机旋转。
- 不连接自动噪声、自动凹凸、发光或全屏油画滤镜。粗笔触已经存在于基色里；强灯光或错误色彩变换仍可能冲淡它。

库内含原色核对渲染及同一柔光下的材质渲染。前者临时用自发光节点展示颜色，**已保存材质全部恢复为 Principled，不带自发光**。

## 验证与边界

已逐张查看原生图，检查方向、材料色彩与粗笔触。骨白首稿因过于接近旧木照片而重画；最终稿增加清楚的灰紫、赭灰和奶油色宽笔块。没有对生成原图使用统一颗粒或照片滤镜。

本轮提供基色和材质起点，**不是完整 PBR 贴图套装，也不是餐厅模型已经完成上色的证明**。法线、位移、空间粗糙度、玻璃、灯光、招牌文字以及物品专属损伤不在本组中。不能从这些颜色图反推可靠的高度或反射率；源文件为平面 PNG，不声称包含手绘分层工程。

整栋模型上的接缝、不同视距、移动镜头、昼夜以及运行性能，需在建模和贴图实装后验证。若需要近景 2K 以上原生细节，应对具体构件重新生成或绘制；不牺牲现有笔触尺度去叠细噪声。
