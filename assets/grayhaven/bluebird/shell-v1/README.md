## 已实现的结构

一楼地板外包络 12 × 10 m，右前角切去 1.3 m；入口在切角面。二楼位于 x=0..6、y=4..10，地面标高 3.2 m，屋顶标高 6.0 m；一楼低屋顶标高 3.4 m。尺寸以米计，仍属于结构图确定的美术设计值。

前部堂座、后部厨房、二楼卧室和起居空间均保留。外墙有实际厚度，门窗与传菜口为真实开洞，窗套、窗台与横档有独立几何。入口和室内门保持空洞，不制作门扇与五金物品。玻璃为简化透明材质。

楼梯位于后厨 x=4.8..5.9、y=6..9.2，沿 -y 上行，16 级、每级高 0.2 m；最高踏步到达 3.2 m。二层楼板在 x=4.8..5.9、y=6..9.3 留洞，上层落脚区域位于洞口前方。楼梯和洞口护栏作为建筑构件制作。

结构图未标墙厚，本轮一楼外墙采用 0.18 m、二楼通常为 0.14 m，二楼右墙为 0.10 m，以在 x=5.9 处与楼梯边缘对齐。二楼前缘下方采用梁和一根柱承接结构示意，不在堂座中增加贯穿墙。屋檐与墙体转角采用拼接边界，避免重叠面形成黑缝。

## 贴图与范围

使用已生成贴图中的 01 骨白挂板、02 蓝绿墙裙、03 窗套、04 雨棚、05 卷材屋顶、07 木地板、08 灰泥。06 吧台、09 卡座、10 转凳不进入本模型，因为本轮不制作这些物体。

UV 按墙面方向、板材行列和构件分区展开，墙裙底部受潮保持朝下。门窗套使用独立漆木贴图，雨棚笔触沿排水方向。颜色贴图为 sRGB，粗糙度沿用材质起点；没有从颜色自动生成法线或添加全屏绘画滤镜。

基座和厨房地面采用中性矿物材质常量，玻璃和窗横档使用单独的简化材质。贴图原图仍保存在上一级贴图包，Blender 与 GLB 都已内嵌所需七张 PNG，不依赖 Codex 缓存路径。专用面板在真实构造分段处裁切复用，远景可以看到重复的大色面，近景独有磨损留待后续定稿。

这是一份贴图建筑壳体。没有桌椅、吧台、灶台、锅杯、电话、床柜、灯具、人物，也未制作街道、周边楼房或环境道具。固定雨棚、窗套、楼梯、护栏和承重梁柱属于本次建筑构造。

## 检查结果

48 个建筑网格对象，40,838 个三角形，0 件物品模型。实际保存文件的 15 项检查通过，包括：地板包络、切角、入口地面、楼板洞口、洞口周围楼板、16 级实际踏步高度、主要门窗开口、UV、七张纹理打包与 GLB 自包含。

逐张检查了 Blender 白模与贴图渲染；浏览器已加载实际 GLB 并检查外观、二楼洞口及一楼白模切换。检查脚本用实际网格射线检查开口和踏步，而非只复述设计参数。

本轮不接入游戏世界状态、拾取、碰撞导航、原运行时剖切或模组尺度。预览页的剖视会隐藏屋顶、上层或临街高墙；它用于资产检查，不声称已实现游戏中的遮光壳。渲染采用中性检查光照，未布置最终室内灯光与天气。

## 在 Blender 查看

打开贴图版即可从默认正交相机查看。Text Editor 中的 `README_AND_VIEWS.py` 可以将 MODE 设为 `exterior`、`ground` 或 `upper` 后运行，切换建筑可见层。白模文件使用相同网格和单独保存的白色材质。

GLB 转换遵循 Blender Z-up → glTF Y-up：Blender 的 (x,y,z) 对应 glTF 的 (x,z,-y)。`floor`、`role`、`side`、`band` 与 `architecture` 位于导出节点的 extras，供后续资产层级使用，不是世界状态字段。
