# 外观风格纠偏 · 尚非定稿

上一版没有达到美术手册要求，只可保留为空间与物品结构原型。此目录是对同一个固定镜头的外观材质、边缘和自然光校正，不是全建筑制作完成声明。

- `exterior-v2.png`：实际 Blender Cycles 渲染，没有对最终图做 AI 重绘。
- `bluebird_exterior_v2.blend`：可编辑的外观试样；从原结构文件派生。
- `exterior_painted_atlas.png`：内置 image_gen 生成的四区平面基色图集。UV 在模型上取样，镜头变化时不会滑动；该图不是手工分层贴图。
- `texture-prompt.txt` 与 `provenance.json`：生成提示词、工具和使用范围。
- `correct_style.py`：UV、材质、屋面条带、倒角与光照的可重复修改脚本。

## 纠正方向

褪色蓝漆临街立面、暖灰旧木侧墙、深色屋面和旧灰白窗框形成材料关系；降低统一圆润的边缘和亮白描边。纹理按墙面连续映射，避免逐块抽样形成马赛克。使用单一方向的海岸午后光，区分临街正面与背光侧墙。

仍需继续检查绘画笔触尺度、重点部位的专门磨损绘制、消失边缘和场景融合。完整室内、GLB、连续昼夜与运行时着色尚未同步。这张外观试样不代表美术验收通过。
